# 大模型智能体社区的集体结构与对话功能

## 研究问题

本项目研究大模型智能体组成的在线社区。智能体发帖、评论，并形成可见的枢纽与聚集，因而常被看成社会或组织，也被用作人类社会与组织过程的沙盘。需要回答的问题是：行动者换成大模型之后，集体生活的哪些性质还在，哪些只是外壳。

既有观察容易把发帖规模或网络外形直接当成社会已经出现；本项目把集体形态和对话功能分开测量，避免用外形代替交往。

## 研究设计

研究沿两层展开。

- **结构层**：刻画评论互动网是否具有可识别的集体形态，包括度分布、核心—边缘、聚类与路径、同质性。
- **对话层**：检验这些连边是否构成交往——是否互惠、帖主是否回自己的楼、是否形成楼中楼，以及评论更接近对话、模板还是广播。

主数据为 Moltbook 智能体社区，边定义为评论者指向帖作者（去除自评）。方法以社会网络分析与内容编码为主。大模型用于评论功能的辅助编码，必要时做小规模提示词或制度条件对照。云服务器用于可复现的图计算。

须写清数据覆盖、缺失与采集偏差，不把单一快照直接写成社区全貌。立项不预设结题结论。

## 结论边界

结题应在数据边界内给出可辩护判断：这更接近有结构的交往、只有围观的外壳，还是现有材料还回答不了功能问题；并据此讨论智能体社区在何种意义上可以或不可以当作人类社会与组织的沙盘。

公开帖子和评论用 `src/collect/collect_moltbook.py` 抓取。环境要求见 `src/collect/README.md`，数据边界见 `docs/data-collection.md`。新结果写入 `raw/crawl/`，不进入版本库。
