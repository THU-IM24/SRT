# 下一步研究计划·精简版

> [原计划](下一步研究计划.md)保留。版本：2026-10-23，研究设计草案，假设不代表结果。

## 1. 研究定位与问题

暂用题目：“智能体社区中形式互惠与内容承接的对应及其测量边界”。分别测量Moltbook评论网的结构与功能，再检验对应。复现与测量边界可作为结题成果，不预设社会性结论。

[四篇论文及近邻书目](../papers/四篇论文概念对照表.md#核心路线引用核实2026-10-23)已覆盖结构、真实性、互惠／论证及约八个月树形与时序。Eziz研究回应概率与等待，Abolhasani等研究二人持续，Zhang等研究挑战—修复；Perez与Sokolova的reciprocity gap卷期2027，完整方法待核实。“更晚、更大”不足以创新；24小时／7天、承接与错配规则均为本项目预设。

| 问题 | 同一快照中的输入与指标 | 起步交付（自启动起） |
|---|---|---|
| **RQ1：形式互惠能否提示内容承接？** | 9月事件、两图及父子正文；比较双向—单向、真实—错配承接率差。 | 第1—2周：核200线程父关系，完成80–120对试标（真实／错配各半）、独立一致性及不可判表；仅判断可行性。 |
| **RQ2：对应是否依赖高产账号或环境？** | 同批标签、月活动量、语言、社区和线程规模；比较去最高产1%、去模板前后的率差。 | 第2—3周：按语言、涉及帖主与否先分层，交样本量和过滤损失；样本不足不细分推断。 |
| **探索RQ3：跨月可见变化与构成、覆盖如何对应？** | 2—9月事件、父关系、捕获时间与计数差异；比较24小时严格回应率及合格分母，分全样本、固定账号面板、首次观察批次。 | 第3—4周：先核2月／9月各200帖的覆盖与可解析率，再做两月基线；覆盖差异明显时只交覆盖报告。 |

固定面板按各比较月均有合格评论的起始评论作者选取，受存活选择影响；首次观察不等于入组。跨月承接须在试标通过后另抽样，不从9月外推。

## 2. 工作假设与可证伪结果

**H1：**同月、同语言且活动相近时，双向对承接率高于单向对，真实对高于同主题错配对。两项分别报告；差异消失或反向时检查精度与覆盖，不换指标追求显著。

**H2：**去最高产1%及模板后，双向—单向承接率差减弱；未减弱则不支持。另比较评论、等线程和等账号权重，不从优质线程外推全平台。

**探索H3：**若后期回应增加，检查固定面板、首次观察批次与全样本是否不同；不能据此分解行为、构成与覆盖的因果贡献。

## 3. 数据与测量口径

统一使用[jscmp4/Moltbook](https://huggingface.co/datasets/jscmp4/Moltbook)的2026-10-07快照，原始输入在`/data/srt/raw/moltbook-2026-10-07/`，合并表为`/data/srt/outputs/{posts,comments}.parquet`。[已有审计及SHA-256](当前数据核查-2026-10-23.md)记录帖子3,699,521条、评论19,728,495条，4,754条评论缺父、6,947条已找到父节点但depth不递增1，另有缺账号和计数差异。计数相等不证明完整，计数不足不全是漏采。

全量审计及9月建图已完成，祖先链、回应机会表和编码待做。9月两图边互惠约6.4%／53.3%，反映边定义影响，不直接解释成社会性差异。

事件表一行一条评论；主网为“评论者→帖作者”，去自评；回复网为“回复者→实际父作者”，顶层指向帖作者，去自回复。两图保存二值边和次数权重，不因互惠较高就换主图。线程树另以消息建节点。

静态边互惠为“有反向边的有向边数／全部合格有向边数”。帖主出现只要求其评论过；严格回应要求帖主24小时内直接回复合格非帖主评论。三步往返要求B、A（帖主）、B沿父子链在起始评论后24小时内完成。两项按合格非帖主评论计机会，每条至多成功一次。7天跨帖再互动仅作扩展：直接回复事件为起点，同对任一方向在另一帖出现即成功，分母须有满7天随访。

每项结果写明UTC窗口、筛选流、分母、权重、不可解析数和不确定性。主规格排平台spam/deleted，保留标记作敏感性检查。以2026-10-07T00:00:00Z为保守观察终点，机会须在此前满24小时／7天；删失机会另列，不记为无回应。足够日历时间仍不保证采集完整。缺父不改接根，原始depth不当重建深度。

## 4. 方法与关键检验

先核查父关系、同帖、时间、自指与环，手查全顶层、交替往返、自回复、缺父和环五种合成线程。选线程按帖子批次，查找父节点与评论使用全体输入，避免切窗制造断裂。

两人独立试标，另两人复核分歧、抽样与上下文。承接须指出父消息内容点及子回复的处理；回答、补充、反驳、澄清和针对性确认均可。模板、新增信息、礼貌另记，不足则“不可判”。先保存独立标签，再讨论；报一致率、κ或α、混淆矩阵和不可判比例。

试标后冻结手册、抽样、估计与敏感性清单。正式预算600–1000对（含错配），依类比例、聚类相关和工作量调整；与试标分离，按线程或作者隔离训练与验证，保留入样概率。承接率=承接数／可判对数，真实与错配分报；另报不可判比例，将不可判全作否／是给出全样本率上下界。

主检验：①按子作者—帖作者（主图）、子作者—父作者（回复图）的当月双／单向关系分别分组，去自环与不可识别对，比较人工承接率；②子回复配给同月、同语言、相近长度和主题的其他父消息，隐藏真假盲审，估计率差；③足够随访样本中比较严格回应、三步往返与承接。主图两端未必实际交谈，当月双向性只作同期关联；错配非天然负标签，往返不等于承接。

先给分层比例与差异区间，再考虑简洁模型。匹配／控制语言、月份、社区、帖龄与前期活动；核心位置用前期窗口，最终karma和未来线程规模不作事前控制。

总体比例用设计权重，另比等线程／等账号结果；按线程、作者或账号对依赖选聚类／分组bootstrap。结构随机基线保留入出度及必要时间、语言机会；内容用同主题错配。报约束、种子、重复数、效应量，区分主检验与探索。

敏感性检查平台标记、重复文本、最高产1%及可解析子集。最高产按各月有效账号／时间且非spam/deleted的评论数（含自回复）排序，阈值并列全纳入，两图共用名单；剔除任一端涉及者。模板先用规范化文本完全重复作代理，模糊模板列探索，报删去的帖子／评论份额。一致性不足则收缩类别；真实对不优于错配则先查测量。自动编码须经独立人工集验证。

## 6. 四人分工与交付

| 角色 | 主责与交叉复核 |
|---|---|
| 数据与复现 | 审计、事件表、manifest、筛选流与重跑命令；结构角色复算。 |
| 结构与时序 | 两图、回应机会、固定随访和手算例；数据角色核边，编码角色核含义。 |
| 内容与编码 | 抽样手册、双标、分歧与独立验证；另一成员独立双标。 |
| 文献与综合 | 前作重合与主张—证据表；全组各复核一篇关键近邻。 |

全员先读[两小时必读路线](../learn/必读路线.md)，再分工上机。共享输入只读，ID／正文留私有输出，公开仅放方法、改写例子和聚合表。DuckDB默认1GB、2线程，长任务放tmux，不并发全量扫描。

当前没有曝光日志、模型与提示词配置、可靠指令采用时点或同口径人类对照；agent_snapshots不能作声誉增长面板。结论限于可见账号和文本关联，不据此推断内部理解、因果机制或普遍人机差异。
