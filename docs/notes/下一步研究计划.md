# 下一步研究计划：互动结构与内容承接的对应及测量边界

> 2026-11-08 修订。保留[README](../../README.md)的立项题目、主网络定义与结题时间，将后续工作收束为一条可完成的测量主线。先读[一页版](下一步研究计划-精简版.md)。以下是研究设计，不是分析结果；历史方案保留在 Git 历史中。

## 一、主线与价值

**主问题：Moltbook 中可见的网络互动，在多大程度上对应回复对上文具体内容的承接？这种对应如何受到连边定义、重复文本和高产账号的影响？**

结构与对话功能已经有直接近邻研究。增加数据量、月份或网络指标不自动形成创新。本项目定位为有明确边界的独立复现与测量检验：先说明网络究竟记录了谁对谁的动作，再用人工内容证据检验这些指标的解释范围。文献增量须逐项比较，不预设首创或显著差异。

信管角度落在**信息系统评价中的测量有效性**：互动次数、双向连边和内容承接是不同层次的证据。借鉴信息质量中的相关性维度，检验活动指标能否为信息回应提供支持；不把相关性等同准确性、任务完成或用户收益。这里使用的是评价视角与可检验指标，不宣称提出了新理论或完整检验信息系统成功模型。

**内容承接**指子回复针对父消息中可指出的具体内容作回答、补充、反驳、澄清或针对性确认。它不要求观点正确，也不证明智能体理解、学习或解决了问题。泛泛赞同、同主题词汇或模板外形都不能单独决定标签。

## 二、三个相连的问题

| 问题 | 做法与交付 | 解释边界 |
|---|---|---|
| **RQ1：边定义改变了怎样的互动记录？** | 对照“评论者→帖作者”与“回复者→实际父作者”两图，说明节点、事件筛选、去自环和静态互惠分母。 | 两图保留的事件不同；互惠差异不是对话质量差异。已有口径核查属于基线。 |
| **RQ2：双向关系中的回复是否更常承接上文？** | 在实际父子消息对上独立双标，比较直接回复图中同月双向与单向关系的承接率及差值；主图分组另作口径对照。 | 同月双向是同期关联，可能发生在不同帖子；不能当作同一线程往返、预测能力或因果效应。 |
| **RQ3：对应是否依赖少数账号、重复文本或样本构成？** | 在同批标签上检查排除高产账号、重复文本前后的结果；仅在样本允许时按语言、社区或顶层／嵌套回复分层。 | 报告过滤损失和区间；不以反复筛选寻找显著结果，不从少数情境外推全平台。 |

技术问答仅可作为样本充足时的情境子集，不作为必做转向。跨月演化、复杂图算法、平台干预和提示词实验不纳入本轮核心交付。

## 三、数据与单位先固定

- 使用 README 指定的 jscmp4/Moltbook 2026-10-07 快照，先以 **2026 年 9 月创建的评论**为试行窗口。父消息从全量输入查找，避免切窗制造缺父。先核语言分布与编码能力，再冻结语言范围；只在实际抽样框内推断。
- 事件表一行一条评论。主网固定为评论者指向帖作者，去自评；辅助回复网指向实际父作者，顶层评论的父消息为帖子，去自回复。两图均保留二值边与次数权重。不能因辅助图互惠更高而替换主图。
- 内容单位为一条真实的“父消息—子回复”对，主比较限于身份、时间和父关系有效且非自回复的事件。保留顶层与嵌套回复，不只挑选优质或热闹线程。主图去自评而排除的帖主回应单列，不能当作主图中的单向关系；跨图比较同时报告各自样本与共同合格子集。
- 主规格排除平台 spam/deleted 标记；先检查实际用到的父关系、同帖、时间、自指和祖先环。缺父不改接根，原始 depth 不直接作为重建深度。所需上下文缺失时标为不可判。
- 静态边互惠为“存在反向边的有向边数／全部合格有向边数”。帖主在楼内出现、实际沿父子链回复、同月双向关系分别记录，不互相替代。若扩展到 24 小时回应率，须另外定义机会分母与完整日历随访，不能由本轮父子对样本推算无回复率。

[已有数据核查](当前数据核查-2026-10-23.md)记录：全量审计与 9 月两图构建已完成；主规格的边互惠约为 6.4% 和 53.3%。这是不同边定义及保留事件的基线，**不是有意义对话的比例，也不是本轮新发现**。祖先链验证、人工双标与语义校验仍待执行。

早期回溯采集、评论抓取门槛、后期回填与回复深度限制都会影响可见关系。计数相等不证明完整，未见反向回复不证明实际没有回复。9 月也须检查覆盖；不把单一快照写成整个社区。

## 四、用小样本把测量做稳

1. **两周试行。** 第一周核查抽样框、父关系及近邻编码定义，形成简短手册；第二周完成 **80–120 个配对任务**的两人独立试标。真实配对须覆盖单向、双向及顶层、嵌套回复；另包含少量同主题错配，分别记录数量。试行用于发现歧义、估计耗时，不用于给平台下结论。
2. **独立内容判断。** 编码者看到父子文本及按统一规则提供的必要上文，不看到网络分组、账号活动量或真假配对标记。每次判断记录父消息的具体内容点、回复怎样处理它，以及“承接／不承接／不可判”；模板、礼貌和新增信息另记。先保存独立标签，再讨论分歧，报告原始一致率、适用的 κ 或 α、混淆矩阵与不可判比例。人工标签也是需要检验可靠性的操作化标准。
3. **错配检查。** 将子回复配给同月、同语言、相近长度和主题的其他线程父消息，避免自配，混入盲审；额外上下文按同一规则呈现。错配也可能承接，不能预置为负标签。真实与错配的差异只用于检查规则是否识别具体承接，不证明理解；若差异不清，先检查标签和配对设计。
4. **冻结正式方案。** 根据试标中的比例、组内相关、区间精度目标和双标耗时确定正式样本量，不把一个未经评估的数量承诺为结题要求。正式集与试标分离，固定抽样框、分层、入样概率及分析清单；不能边看显著性边加样本。若用模型辅助编码，须在隔离线程或账号的人工保留集验证后再扩展。
5. **比例与差异。** 真实样本的承接率＝承接对数／可判对数；另报不可判比例，并将不可判全作否／是给出全部合格对的上下界。分层抽样的总体比例使用设计权重；错配结果单报。给出双向—单向率差及区间，按线程或账号对的重复依赖设计聚类估计；试行不足以支持推断时只报计数与可行性。
6. **少量稳健性检查。** 重复文本先采用公开说明的规范化完全重复规则，不能直接将重复标签当作不承接。高产账号按 9 月有效账号／时间且非 spam/deleted 的评论量（含自回复）确定前 1%，阈值并列全部纳入，剔除任一端涉及者；两图使用同一名单。分别报告去除前后的样本、评论份额和差值；分层不足就合并或停止细分。若使用模型控制，只纳入定义明确的变量，不把最终获赞和未来活动当事前原因。

虚构示例：上文问“某 API 返回 429，应检查什么？”，回复“这很重要”仅凭这句话不足以判定承接；回复“先核对调用配额和重试间隔”针对了具体问题，可判承接。但后者是否正确、是否解决问题，需要本研究之外的证据。

## 五、文献怎样服务主线

- [Zerhoudi 等：形式与功能](../papers/Zerhoudi-2026-形式与功能.md)是最直接的重合核查对象；对照边定义、论证关系、人工或自动标签和样本。不能宣称首次研究结构与内容的关系。
- [Holtz](../papers/Holtz-2026-Moltbook社交图.md)与[Price 等](../papers/Price-2026-Moltbook早期网络.md)用于对照连边、重复文本和采集范围。不同快照、窗口与指标不能直接作社会性高低排名。
- [Eason Chen 等](../papers/EChen-2026-类似同伴学习.md)帮助核对回复类型及文本与学习的区别；[Huo 等](../papers/Huo-2026-技术讨论.md)说明技术话语具体性已有研究。两篇均为预印本。
- [Ameri 等](../papers/Ameri-2020-信息质量.md)帮助区分回复量、相关性与专家质量评价；[Qiu 等](../papers/Qiu-2024-知识寻求与贡献.md)提供信息行为背景，但人类动机不能直接移植到智能体。

[四篇补充文献与 PDF](../papers/2026-11-08-信息系统视角文献.md)保存在原文献目录，按用途阅读，不扩大必读路线。正式写作前完成“前作问题—数据单位—测量—本项目差别”对照；重合部分明确写作复现。

## 六、完成标准与时间

| 时间 | 必须交付 |
|---|---|
| 2026 年 11 月；试行自启动起两周 | 两图口径与覆盖说明、抽样框、试标手册、独立一致性及耗时记录。复用已有审计，不重复包装基线。 |
| 2026 年 12 月—2027 年 1 月 | 冻结方案后的正式双标；结构分组与承接对照；重复文本、高产账号及覆盖的敏感性检查。 |
| 2027 年 2 月 | 结题报告、主张—证据表、可复现的方法与聚合结果。 |

团队按数据与口径、结构与抽样、内容双标、文献与报告分工；至少两人独立参与编码，分歧不能由单人标签冒充一致性。若试标不稳定，先收缩标签并另取新样本复试；若数据不足，收缩推断范围并报告不能识别之处，不预设最终结论。

答辩中的核心证据链是：**数据覆盖 → 两种互动定义 → 独立内容测量 → 对应关系及稳健性 → 指标解释边界。** 可辩护的贡献是说明哪些互动指标能够或不能支持什么判断；不声称证明智能体内部理解、社会形成、实际信息收益或平台改进的因果效果。

正文、账号 ID、标签明细与私有衍生表留在私有分析目录；公开仓库仅放方法、许可材料、虚构示例及经核查可公开的聚合结果。服务器按月、按列处理，不并行全量构图。
