# 研究计划：同样的文字，不同的命运

> 2026-11-15 方向调整稿，**待导师／组会确认后才算正式变更**。在确认前，立项题目、结题时间仍以[README](../../README.md)为准。旧主线（互动结构与内容承接的对应及测量边界）已归档，见[旧详细方案](archive/2026-11-08-互动结构与内容承接-详细方案.md)和[旧一页版](archive/2026-11-08-互动结构与内容承接-一页版.md)。以下是研究设计，不是结果；预备数字见[预备分析](预备分析-2026-11-15.md)，均为描述性、待复核。一页版见[精简版](下一步研究计划-精简版.md)。

## 一、为什么调整

1. 旧主线的结论多是“测量边界”，故事感弱，且结构与对话功能已有直接近邻研究（见[重合核查](文献检索与方向重合核查-2026-10-23.md)）。
2. 旧计划里的“同质性”分支，预备检验显示简介相似几乎不影响评论对象（优势比约 1.03／标准差；general 版面约 1.00），与文献一致，不适合作头条。
3. Moltbook 有一类别处难得的数据：**平台自己产生的“双胞胎”**——完全相同文字的帖子被不同账号在不同时间发出；完全相同简介的 agent 被批量或独立地创建。它们让“内容”“人设”被固定，剩下的差异才能归因。这是机器版的 Music Lab。

## 二、核心问题与故事

**一句话**：把“说了什么”或“被设定成什么样”固定住，agent 社会里的成败还剩多少由内容决定？多少来自时机、版面、作者声望、运营者，多少只是运气？

| 问题 | 固定什么 | 看什么 |
|---|---|---|
| **RQ1：同样的话，不同的命运**（选题 A） | 帖子文本完全相同 | 点赞与评论的组间相关；发布顺序、小时、版面、作者声望的贡献；早期优势是否在暴露时间校正后仍在 |
| **RQ2：谁造的 agent，比人设写了什么更重要**（选题 B） | 简介文本完全相同 | 批量创建（运营者式）与独立采用两类家族的结果相似度；人设文本、运营者与运气的贡献 |
| **RQ3（附加）：agent 会改写自己吗**（选题 C） | 同一 agent 前后快照 | 简介编辑是否发生在点赞或 karma 冲击之后 |

RQ1 与 RQ2 共用一个框架：**组间相关（ICC）＋ 置换零分布 ＋ 方差分解**。RQ3 作为附加分析，只在 RQ1／RQ2 站稳后做。

## 三、意义

- **平台与治理**：热门帖在多大程度上是位置与时机的产物，而不是内容的产物。对推荐排序和“曝光公平”有直接含义，不限于 Moltbook。
- **智能体评测**：点赞、karma 常被当作 agent 的“质量”指标。如果同文帖结果差异大，这些指标作为质量代理的有效性就有边界。
- **人设设计**：提示词（人设文本）在野外部署中到底有多大作用；受控实验认为人设有效（Wilson 等），野外是否也成立？
- **社会科学**：Salganik 等的 Music Lab 研究人类文化市场的不平等与不可预测性；LLM 版已有受控实验（Hashemi 等；Chupilkin）。野外平台上的“自然实验”是补充，不是替代。

## 四、假设（均待检验，不预设结论）

- **H1**：同文组之间点赞存在显著组间相关（ICC 高于置换零分布）；加入发布小时、版面、作者声望后，ICC 明显缩小，缩小的部分归于“内容之外”。
- **H2**：同文组内越早发出的帖子点赞越多；在暴露时间校正后仍成立，则支持早期优势，不成立则主要是累积时间的假象。
- **H3**：批量创建的克隆家族组内相关高，独立采用的家族组内相关低；即运营者效应大于人设文本效应。
- **H4（附加）**：高点赞或 karma 跃升之后，agent 编辑简介的概率上升。

零结果同样是结果：若同文帖的命运几乎由时间和作者解释，说明“内容不重要”；若组间相关在控制后仍高，说明内容或未观察的共同来源起作用。

## 五、数据与变量

使用 README 指定的 jscmp4/Moltbook 2026-10-07 快照。变量按“固定哪一部分”组织：

- **同文组（RQ1）**：帖子标题与正文拼接，转小写、合并空白，取前 600 字符哈希；入选条件至少 20 帖且至少 10 个不同作者（预备值：704 组、143,101 帖）。结果变量：点赞、评论数；协变量：发布时间（小时、星期、距上线天数）、版面、作者 karma 与粉丝数（抓取时的值，不是事前变量）、作者创建时间、平台 spam 标记。后续扩展到近似重复（去掉签名、链接、数字后再比对）。
- **克隆家族（RQ2）**：规范化后完全相同的简介（长度至少 15）、家族至少 10 个 agent；家族特征：创建时间 P10–P90 跨度、spam 占比、是否铸币／自动化关键词。结果变量：每个 agent 的总点赞、发帖数、评论数。**简介表是私有文件，不进仓库**（见 `AGENTS.md`）。
- **快照面板（RQ3）**：帖子内嵌的 author 结构带抓取时的简介和 karma，以及抓取日期 `_scraped_at`（预备值：183,155 个作者、153 个抓取日；约 179 万帖该字段为空）。`agent_snapshots` 表没有简介字段，不是增长面板。

数据边界：所有计数是抓取时的累计值；没有 feed 曝光日志；平台排序算法未知；不能随机分配。这些必须写进每个结论。

## 六、方法

1. **组间相关与置换零分布**：对数点赞（log(1+x)）做单因素 ICC（不平衡设计用校正的平均组大小），再把标签在个体间打乱得到零分布。报告观察值、零分布均值与最大值，不只报显著性。
2. **方差分解**：依次加入“组固定效应（内容）→ 小时与版面 → 作者声望 → 残差”，用多种加入顺序的平均（类似 Shapley）避免顺序依赖；点赞稀疏时同时做“是否至少一个赞”的二分类版本。
3. **组内顺序与暴露时间校正**：在同文组内，用固定效应回归检验相对发布顺序与点赞的关系；用抓取日期或帖龄校正累计时间；对 `_scraped_at` 为空的帖子，先核实可否用其他字段补上，否则单独分析并标注。
4. **混合模型**：同文组或家族作随机截距，固定效应含小时、版面、对数 karma、帖龄；若需 `statsmodels`，先向团队申请，**不擅自安装到共享环境**；备选是用 numpy／scipy 实现分组去均值回归与聚类稳健标准误。
5. **批量与独立的划分**：用创建时间爆发度、spam 占比、关键词作初筛，阈值作敏感性分析（跨度 3／7／14／30 天，spam 占比 0.1／0.3／0.5），并检查语义相同但文字不同的简介（TF-IDF 或嵌入近邻合并）。
6. **稳健性**：排除 spam 标记、铸币／自动化账号、单一作者占比过高的组；分月、分版面、按语言重复；与旧计划中已做的数据核查口径对照。
7. **作者重叠**：同一组里一个作者发多次会让“独立”失效，所有标准误按作者或家族聚类。

## 七、预备证据（描述性、待复核）

详见[预备分析](预备分析-2026-11-15.md)。要点：

- 同文帖占全部帖子的 9.0%（50,567 组共 334,212 帖）；可用组 704 个、143,101 帖、45,827 个作者。
- 同文组的对数点赞 ICC 为 0.354（置换对照约 0），组内越早发越多赞（261 个有变异的组中 80.5% 为负相关）；但点赞稀疏、抓取累积时间可能混淆。
- 同简介家族：29,320 个 agent 在重复简介组里；至少 20 成员的大组 46.7% 在 24 小时内创建完毕，组内 ICC 0.707；严格口径的独立采用家族仅 22 组、568 个 agent，ICC 0.028。

这些数字支持“值得做”，**不支持任何因果表述**。

## 八、风险与对策

| 风险 | 对策 |
|---|---|
| 抓取时累计点赞混淆“早发更多赞” | 帖龄／抓取日校正；只用抓取日相近的子样本；明确写成关联 |
| `_scraped_at` 约 179 万帖为空 | 第一周核实原因；无法补则分开分析 |
| 同文组多为模板、刷屏、批量账号 | 作者数门槛、spam 排除、单作者模板与多作者模板分开 |
| 独立采用家族样本太小（预备 22 组） | 阈值敏感性；加入近似简介；若仍小，RQ2 降级为“批量对独立”的对照描述 |
| “爆发式创建”不是真实的运营者标识 | 只称“运营者代理变量”；不宣称识别了运营者 |
| 点赞稀疏，信号弱 | 二分类与零膨胀版本；评论数作第二结果；必要时改用更长时间窗 |
| 与已有 Music Lab（Hashemi；Chupilkin）重合 | 写清差别：我们是野外自然实验、固定的是平台内文本与人设；不宣称“首次” |
| 公开仓库的隐私与伦理 | 不放正文、账号 ID、简介明细；只放聚合与方法；示例用虚构文本；见[数据暴露与研究伦理](../learn/concepts/数据暴露与研究伦理.md) |
| 研究设计只是设计，未经导师确认 | 先在组会上确认方向，再按下表推进 |
