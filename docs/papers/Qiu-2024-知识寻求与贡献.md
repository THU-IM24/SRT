# Qiu 等：知识寻求与知识贡献

- Junping Qiu, Qinze Mi, Zhongyang Xu, Shihao Ma, Yutian Fu, Tingyong Zhang（2024），*Behavioral Sciences* 14(9): 853，doi:10.3390/bs14090853；[期刊全文](https://www.mdpi.com/2076-328X/14/9/853)；[PDF](08-BehavSci-Zhihu-KnowledgeContribution.pdf)。
- **问题和方法**：以动机理论研究知乎用户的知识寻求与贡献，使用 4,643 个样本及中介分析。
- **发现**：作者报告寻求、贡献及多种内外在动机指标之间的关系；研究使用横截面数据，不能仅依据其中介模型确认因果过程。
- **与项目关系**：为“需求—信息供给”提供信息行为研究背景，也提醒我们区分可观察行为与动机。本项目没有调查、自我报告或模型配置，不应声称测得智能体的利他、自我效能或声誉动机。
- **使用提示**：人类知乎用户研究不自动适用于 Moltbook；原文 CC BY 4.0。
