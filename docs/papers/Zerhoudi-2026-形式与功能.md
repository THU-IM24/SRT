# Zerhoudi 等：Form Without Function

- 编号：03。Saber Zerhoudi 等12位作者。
- 仓库PDF为arXiv:2604.13052v1；文件封面日期与arXiv显示的版本日期存在不同呈现，引用时用版本号并核对正式元数据。
- [arXiv入口](https://arxiv.org/abs/2604.13052)、[对应HTML](https://arxiv.org/html/2604.13052v1)。原文：`03-Passau-Moltbook-FormWithoutFunction.pdf`。
- 阅读范围：§3–10及附录，特别是数据、互动、内容、指令与局限。

## 核心问题及与本项目的重合

作者直接问Moltbook是否具有功能性的社会互动，而非仅复制社交媒体形式。它已覆盖帖主回楼、回复深度、互惠、论证关系、社区一致性、简介—行为一致性及指令变更。原项目的大问题与它高度重合，不能再声称“首次把结构和功能分开”。

## 数据及分母

原文覆盖2026-01-27至03-09，共1,312,238帖子、约670万评论。表1同时说明原始抓取量与去重后量；抓取、清洗、过滤、进入具体分析的样本不同。不能把某个子样本比例乘到当前1973万评论上。

## 三层分析

互动层：活动集中与退出、动作间隔和突发、首次评论时间、帖主出现、平坦线程、独白、点赞/karma和双向关系。内容层：简介与实际发帖、社区名与内容、主题熵、URL生态以及父子文本关系。指令层：收集Wayback中的skill、heartbeat、rules档案，将版本变化与行为时间序列对照。

论证分类使用支持、冲突、改述、无论证关系四类。No relation不是所有交往功能的否定。安全部分另外采用9类内容与5级风险、专家种子标注、嵌入和最近中心分类，并分析信息暴露和攻击话语。这些不是本项目都要实施的任务。

## 不能直接照抄的地方

- 互惠需要核对有向边和无序双向对：原文报告的3.3%接近2×18,855/1,151,825。
- 正文不同位置给父帖与顶层评论词汇重叠0.69%和3.2%的表述，不擅自替作者解释差异。
- 快速、突发、低词汇重叠可以有多种原因，不独自证明没有理解、没有目的或有人类控制。
- 指令前后比较缺少账号采用日志及严格对照时，因果归因仍有限。
- 基于人类论辩训练的模型可能漏掉智能体特有表达，需本地人工验证。

## 可继续追问但必须重新查重

原文承认最后一次回楼优先指令只有很短后随访，也承认词袋方法与短窗口限制。我们可以考察长期变化、真实父子文本承接与测量误差，但“长期”“语义”“关系持续”都已有后续研究，详见检索记录。可行性来自当前数据，不自动带来原创性。

**复习问题**：为什么“帖主出现”和“帖主回应别人”不是同一指标？为什么“无论证关系”不能翻译成“无任何功能”？
