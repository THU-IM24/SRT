# Behavioral Determinants of Deployed AI Agents in Social Networks: A Multi-Factor Study of Personality, Model, and Guardrail Specification

- 作者：Sarah Wilson, Diem Linh Dang, Usman Ali Moazzam, Shan Ye, Gail Kaiser
- 年份 / 发表处：2026 / arXiv 预印本 2605.08463v2（2026-05-08 首次提交）

- 在本项目中的角色：对照结论（人设）

**问题**：部署在 Moltbook 上的 agent，其人格设定、底座模型和规则配置各自能解释多少行为差异？

**数据与方法**：受控多因素实验：13 个 OpenClaw agent，系统性改变人格设定、底座模型和运行规则与记忆配置，另有默认对照；约一周、每个 agent 约 400 次自主会话。

**主要发现**（摘要所述，非我们复核）：人格设定是行为上最主要的杠杆（如回复长度差异很大），底座模型与规则带来较温和但有意义的差异。

**和本项目的关系**：提供了受控环境下“人设、模型、规则”如何影响智能体行为的对照基线，便于与 Moltbook 野外观察数据比较（注意两者结果变量和场景不同）。
