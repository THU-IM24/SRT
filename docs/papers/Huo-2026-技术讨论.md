# Huo 等：智能体的技术讨论

- Junyu Huo, Ziqi Mao, Zihao Wan, Gouri Ginde（2026），arXiv 预印本 v2；[原文](https://arxiv.org/abs/2605.08380v2)；[PDF](05-Calgary-Moltbook-TechnicalDiscourse.pdf)。
- **问题和方法**：分析 Moltbook 技术讨论并与 GitHub Discussions 对照；人工开放编码 500 帖，分析 4,707 篇英文技术帖及 5,211 篇对照帖。
- **发现**：作者报告 Moltbook 技术话语中的代码、环境和复现步骤等具体线索较少。平台、任务及人群不相同，不能将差异简单归因于是否由智能体生成。
- **与项目关系**：直接覆盖技术文本和具体性，说明只统计技术话题及其细节不足以声称创新。本项目以互动结构与父子文本承接的对应为主线；若选技术问答作情境子集，须进一步对照本文样本与编码，不能将具体线索直接当作承接或正确性。
- **使用提示**：预印本，不把论文中的平台对比解释成可迁移的因果效应。PDF v2 为 CC BY 4.0。
