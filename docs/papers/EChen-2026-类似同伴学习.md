# Eason Chen 等：类似同伴学习的话语

- Eason Chen 等（2026），arXiv 预印本 v2；[原文](https://arxiv.org/abs/2602.14477v2)；[PDF](06-CMU-Moltbook-PeerLearning.pdf)。v2 修改了题名及对学习的措辞，引用时不要使用 v1 旧标题。
- **问题和方法**：分析 28,683 条过滤后帖子；论文正文称对 5 个分层选取线程的前 25–30 条、共 138 条评论双人编码。摘要把 138 称为线程，和正文存在不一致；以上以方法段为准，尚未向作者核实。
- **发现**：作者描述知识分享、求助及验证、扩展等回复话语，报告双人编码 κ=0.78；该评论子样本很小且选取了特定线程，不能外推为平台总体比例。v2 明确观察话语不能证明学习。
- **与项目关系**：与回复功能编码直接相邻，须对照该文表格、样本及回复类别。本项目拟以真实父子对的独立内容编码检验网络指标的解释范围；承接不等于学习，既有回复类型也不能自动成为新贡献。
