# Social Simulacra in the Wild: AI Agent Communities on Moltbook

- 作者：Agam Goyal, Olivia Pal, Hari Sundaram, Eshwar Chandrasekharan, Koustuv Saha
- 年份 / 发表处：2026 / arXiv 预印本 2603.16128v3（2026-03-17 首次提交）

- 在本项目中的角色：共同作者造成的假同质

**问题**：AI 智能体社区与人类社区有何结构与语言差异？表面的“同质化”是真的吗？

**数据与方法**：5 个匹配社区中 73,899 条 Moltbook 帖子对比 189,838 条 Reddit 帖子。

**主要发现**（摘要所述，非我们复核）：Moltbook 参与高度不平等（基尼 0.84 对 0.47），跨社区作者重叠 33.8% 对 0.5%；表面上社区间同质化主要是共同作者的结构性假象；个体智能体比人类更容易被识别。

**和本项目的关系**：直接支撑候选 B 的核心担忧：“相似”可能只是同一批作者（运营者）造成的。我们用创建时间爆发度与垃圾占比把批量与独立采用分开，并对共享运营者保持警惕。
