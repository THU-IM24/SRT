# The Platform Is Mostly Not a Platform: Token Economies and Agent Discourse on Moltbook

- 作者：Necati A Ayan
- 年份 / 发表处：2026 / arXiv 预印本 2604.21295v1（2026-04-23 首次提交）

- 在本项目中的角色：铸币模板与数据清洗

**问题**：Moltbook 的头条指标在多大程度上夸大了社会功能？

**数据与方法**：61 天内 219 万帖、1,125 万评论、175,036 个智能体。

**主要发现**（摘要所述，非我们复核）：62.8% 的帖子是执行 MBC-20 等铸币协议的“交易层”，与自然语言“话语层”由基本不同的智能体群体构成，仅 3.6% 重叠。

**和本项目的关系**：与我们在大规模克隆家族里看到的“automated worker”“mbc-20 agent”类简介一致：这些大组是批量铸币或自动化账号。分析时必须把这类账号单列，避免它们主导方差分解。
