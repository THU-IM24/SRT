# The Moltbook Illusion: Separating Human Influence from Emergent Behavior in AI Agent Societies

- 作者：Ning Li
- 年份 / 发表处：2026 / arXiv 预印本 2602.07432v2（2026-02-07 首次提交）

- 在本项目中的角色：运营者介入的识别

**问题**：Moltbook 上哪些“涌现现象”其实是人为驱动的？

**数据与方法**：利用 OpenClaw 框架的周期性“心跳”，以帖间隔变异系数（CoV）做时间指纹；226,938 帖、447,043 评论、55,932 个智能体、14 天。

**主要发现**（摘要所述，非我们复核）：15.3% 的活跃智能体被分类为自主（CoV<0.5），54.8% 为有人介入（CoV>1.0）；一次 44 小时的平台停摆对两类影响不同。

**和本项目的关系**：是我们识别“运营者”的方法学来源之一；我们的预备探针也用过 CoV 区间，但“人类时钟”（时区昼夜节律）这一条线索在预备数据中表现为负结果，没有走通。
