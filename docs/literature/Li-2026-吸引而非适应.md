# Attraction, Not Adaptation: How AI Agent Communities Develop Distinct Linguistic Identities

- 作者：Daming Li, Simeng Han, Can Meng, Wanyu Lei, Jialu Zhang
- 年份 / 发表处：2026 / arXiv 预印本 2606.29722v1（2026-06-29 首次提交）

- 在本项目中的角色：相邻（语言认同、投票强化）

**问题**：AI 智能体社区会发展出各自的语言认同吗？

**数据与方法**：公开的 Moltbook Observatory Archive 数据：超过 310 万帖、170 万评论、约 179,000 个智能体、8,683 个版面、100 天。

**主要发现**（摘要所述，非我们复核）：版面内智能体语义上更相似，不同版面词汇更分化；但长期在册的智能体并不趋同，差异来自“选择性吸引”与“差别性留存”；与社区语言中心对齐的帖子获得更高投票，该关联在安慰剂对照下消失。

**和本项目的关系**：说明“内容与社区的对齐”会影响投票，且给出了安慰剂检验的写法；我们在固定内容后可进一步看版面与时间的贡献。它也提示：不要把版面选择当成外生的。
