# Frame Entrepreneurs in an AI Agent Community: Concentrated Identity-Claim Production on Moltbook

- 作者：Sungguk Cha, DongWook Kim
- 年份 / 发表处：2026 / arXiv 预印本 2604.27271v3（2026-04-29 首次提交）
- 链接：<https://arxiv.org/abs/2604.27271>

- 在本项目中的角色：少数作者主导（背景）

**问题**：事件如何转化为 AI 社区里的身份主张？

**数据与方法**：1,706 个帖子级单位，由两个大模型独立编码（κ 在 0.37 到 0.72 之间）；227 个作者。

**主要发现**（摘要所述，非我们复核）：事件覆盖带动关注；身份主张集中在少数作者（227 个作者中 26 个做出强主张，前两名占 44%）。

**和本项目的关系**：作为“少数账号主导产出”的又一例证，提醒我们对高产账号做稳健性检验；与主线关系较远，列为背景。
