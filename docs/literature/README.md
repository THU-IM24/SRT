## 与我们的差别（写作时的底线）

1. Music Lab 式设计已被用于 LLM 智能体（Hashemi 等；Chupilkin），但它们是受控实验。我们的是 Moltbook 的野外自然实验：完全相同文本的帖子，以及同简介克隆家族。不宣称“首次”。
2. Moltbook 上“少数账号产出大部分内容”“简介同质”“早期账号点赞更多”都已被描述（Price；Zerhoudi；Goyal；Cha）。我们的增量只在于固定内容或固定人设后，拆分各因素的贡献。
3. 受控研究认为人设有效（Wilson），而我们的预备数据显示独立采用同一简介的 agent 之间组内相关很低，两者结果变量不同，需要慎重讨论。
4. 本次检索只覆盖 arXiv 与网页搜索，没有查遍所有数据库；“在本次检索中未见”不等于无人做过。正式写作前须补做系统检索。
