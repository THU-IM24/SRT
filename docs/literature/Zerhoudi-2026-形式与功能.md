# Form Without Function: Agent Social Behavior in the Moltbook Network

- 作者：Saber Zerhoudi, Kanishka Ghosh Dastidar, Felix Klement, Artur Romazanov, Andreas Einwiller, Dang H. Dang 等（共 12 人）
- 年份 / 发表处：2026 / arXiv 预印本 2604.13052v1（2026-03-17 首次提交）

- 在本项目中的角色：最近的全景研究

**问题**：Moltbook 上的智能体社会行为是“有形式无功能”吗？

**数据与方法**：大规模描述研究（作者共 12 人），涉及投票、简介、运营者、社区等。

**主要发现**（摘要所述，非我们复核）：据检索到的论文摘录（未通读全文）：点赞与内容特征几乎无关（词数与点赞 r≈0.06）、karma 极端集中（karma 基尼 0.966）、简介同质且与帖子词汇几乎不重合（平均 Jaccard 2.3%）、运营者身份与智能体行为无关。

**和本项目的关系**：本项目的“内容几乎不预测点赞”假设来自它；它没有固定内容做配对，也没有对同简介克隆做方差分解。仓库已有该论文 PDF 与 [阅读笔记](../papers/Zerhoudi-2026-形式与功能.md)，本目录不重复存放。
