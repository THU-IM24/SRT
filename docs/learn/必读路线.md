# 必读路线：15页抓住研究主线

核心共 **15页：11个概念页＋4个教程**，按下列顺序读，约2小时；上机、运行练习和正式标注另计。
先读各页导语、核心例子与表格；页内选读小节、来源书目和延伸链接按需查，不增加必读页数。
核心页统一以账号图、父子消息对和起始评论机会区分计数单位；24小时／7天均是项目预设窗口。

## 核心阅读顺序

1. [结构与功能](concepts/结构与功能.md)：先分清网络外形与互动功能，读完能说明为什么连边多不等于发生有效对话。
2. [数据快照与覆盖](concepts/数据快照与覆盖.md)：先确认观察边界，读完能区分行为缺失与采集缺口。
3. [01 核查环境与数据边界](tutorials/01-核查环境与数据边界.md)：把边界落实到输入和环境，读完能核对快照版本、字段与资源限制。
4. [网络边定义](concepts/网络边定义.md)：明确评论究竟指向谁，读完能手算主网络、直接回复网络与线程树，并区分两种自回复过滤。
5. [互惠性](concepts/互惠性.md)：看清双向关系的计数单位，读完能手算边互惠、账号对互惠与加权互惠，并解释静态双向关系的局限。
6. [02 建立事件表与两种网络](tutorials/02-从Parquet建立事件表与两种网络.md)：把定义接到建表流程，读完能说明过滤规则及父节点为何不能随分析窗口一起截断。
7. [回复树](concepts/回复树.md)：先核实消息父子关系，读完能识别缺父、环和自回复对树形指标的影响。
8. [帖主回楼](concepts/帖主回楼.md)：拆开出现、直接回应和完整往返，读完能为三种比例选分母，并识别完成往返后的新起始机会。
9. [右删失](concepts/右删失.md)：避免把观察不足当作不回应，读完能筛选完整24小时或7天随访机会，区分随访不足与覆盖缺口。
10. [时间互惠](concepts/时间互惠.md)：把双向连边推进到有序往返，读完能定义同线程、按时间发生的持续互动。
11. [04 核对回复树与帖主回应](tutorials/04-核对回复树与帖主回应.md)：用受控线程检验上述定义，读完能手核回楼、三步往返及其观察窗口。
12. [语义承接](concepts/语义承接.md)：把功能判断落到父消息的具体内容，读完能区分承接、同主题、礼貌和不可判。
13. [抽样设计](concepts/抽样设计.md)：明确要代表哪类对象，读完能区分父子对、线程和账号的估计目标，解释分层及两阶段入样权重。
14. [内容编码与一致性](concepts/编码一致性.md)：把标签定义与可靠性连起来，读完能安排独立双标，解释κ与一致率差异，并处理不可判和共识标签。
15. [06 抽样与人工编码对话功能](tutorials/06-抽样与人工编码对话功能.md)：串起抽样和人工验证，读完能列出试标、真实／错配父子对、权重与一致性检查步骤。
