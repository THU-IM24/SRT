# 08 复现与小规模机制实验设计

**目标**：理解哪些原文能用现有快照复现，哪些需要额外数据；准备一个无需真实平台发帖的实验方案。
**先读**：[基于智能体的模型（含角色与提示词）](../concepts/基于智能体的模型.md)、[模拟有效性](../concepts/模拟有效性.md)。

## 1. 做复现清单

01的点赞图只能做方法迁移，不能用评论图声称精确复现。02是生成实验，需要角色、规则、模型参数与调用预算。03的宽松帖主出现、静态互惠可以重新测量，但其数据集不同；指令效应需要外部历史。04的讨论规模、树形和时序部分可对照，但历史点赞饱和检验需要重复帖子面板。

每项复现记录：原文版本、图表/公式、原始分母、我们的对应分母、不可获得的变量。对不上时叫“迁移检验”或“独立样本复现”，不叫精确数值复现。

## 2. 选择一个小问题

候选：回楼提醒是否只增加回复次数，还是也增加有针对性的内容承接？它与03的指令讨论相关，需要与后续实验文献再次查重。先写可检验结果，再决定用什么模型。

## 3. 因子设计草案

一个可控起点是2×2：是否提供线程记忆摘要×是否给出明确回楼步骤。各组使用相同任务、账号数、轮数、token上限和可见信息。把每个独立运行的线程群作为随机化单元，避免同一组代理跨处理条件共享记忆。

例如每条件10个独立重复只是预算草案，不是功效计算结论。先用廉价试运行估计方差，再决定重复数。全部在离线沙箱中，不向真实Moltbook写入内容。

## 4. 明确结果与成本

主结果：在固定轮数内完成具体问题的正确率，或经盲审的父子承接率。次结果：直接回复概率、严格往返、重复率、延迟与token成本。若没有可验证任务，不能把长链本身叫协作成功。

## 5. 控制生成器

别一组用随机连接，另一组用优先连接，再把差异归因于提示词。可把关系选择与文本生成分别固定或消融。模型、版本、提示、温度、工具权限、运行顺序和失败重试都保存到manifest。

温度0仍建议多次运行。输出的“我记得你”不是有持久记忆的证据；检查实际提供了哪些历史信息。

## 6. 决策规则

若提醒只增加数量而不增加承接，报告程序性遵从与功能改善的区别。若记忆提高任务表现但成本陡升，报告收益—成本而非只报最佳结果。若所有组都很强，检查任务是否过易；若都失败，检查输入和执行链是否正常。

## 7. 本次交付范围

本次仅完成设计与可执行数据基线，不调用付费模型、不部署大模型、不改公共环境。下一步若团队选择该路线，先把预算、任务集、模型与判定规则落实，再进行试验。观察性Moltbook分析与沙箱因果结果分开报告，不能相互替代。
