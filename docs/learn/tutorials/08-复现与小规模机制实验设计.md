# 08 复现与小规模机制实验设计

**版本**：2026-10-30 复核版
**目标**：区分精确复现、独立样本复现、方法迁移和机制实验；准备一个不向真实平台发帖的小规模设计。
**先读**：[基于智能体的模型（含角色与提示词）](../concepts/基于智能体的模型.md)、[模拟有效性](../concepts/模拟有效性.md)。

> 研究方向已有直接重合工作。先完成文献对齐和观察性基线，再决定是否做实验；有方案不等于已有实验结果。

## 1. 做复现清单

当前快照和论文的数据、字段、采集制度并不完全相同，因此逐项记录：原文版本、图表/公式、原始分母、我们的对应分母、缺失变量、可比范围和不可比原因。

- 只拿评论图去重画原文点赞图，是**方法迁移**，不是精确复现。
- 角色、规则、模型参数和调用预算都不同的生成实验，是**独立样本/条件复现**，不能声称数值重现。
- 结构、树形和时序可以做同口径对照，但要保留数据快照与采集边界。

## 2. 选择一个小问题

候选问题：回楼提醒是否只增加回复次数，还是也增加有针对性的内容承接？先写可检验的主结果，再决定模型、任务集和人工判定；同时检查已有研究是否已经覆盖该问题。

不要把“链更长”“输出更长”直接当作协作成功。结果必须能被固定规则或盲审验证。

## 3. 因子设计草案

一个可控起点是2×2：是否提供线程记忆摘要 × 是否给出明确回楼步骤。各组保持相同任务、账号数、轮数、token上限、可见信息和停止规则；每个独立运行的线程群是随机化单元，避免同一组代理跨条件共享记忆。

每条件10个独立重复只是预算草案，不是功效结论。先用廉价试运行估计方差、失败率和成本，再决定正式重复数。全部在离线沙箱运行，不向 Moltbook 写入内容。

## 4. 明确结果与成本

主结果可选：固定轮数内完成具体问题的正确率，或经盲审的父子承接率。次结果：直接回复概率、严格往返、重复率、延迟、token成本、失败重试和人工审核时间。

若没有可验证任务，不能把链长、代理自述或“记得你”当作持久记忆或协作的证据。

## 5. 固定生成器和 manifest

不要一组用随机连接、另一组用优先连接，再把差异归因于提示词。关系选择与文本生成应固定或明确消融。manifest 至少保存：模型和版本、system/user prompt、温度及其他采样参数、工具权限、随机种子、运行顺序、失败重试、输入摘要哈希、输出判定版本和成本。

温度0也建议多次运行；输出声称“我记得你”不代表模型实际获得了历史信息，必须审计传入上下文。

## 6. 决策规则

- 提醒只增加数量、不增加承接：报告程序性遵从与功能改善的区别。
- 记忆提高任务表现但成本陡升：报告收益—成本，而非只报最佳结果。
- 所有组都很强：检查任务是否过易、评分是否泄漏。
- 所有组都失败：先查输入、执行链、工具权限和停止条件。

观察性 Moltbook 分析与沙箱机制结果分开报告；后者不能自动证明真实社区有效，也不能替代人工验证。

## 7. 当前交付边界

当前只完成设计和可执行数据基线：不调用付费模型、不部署大模型、不改公共环境、不向真实平台发帖。团队选择路线后，先冻结预算、任务集、模型、判定规则和停止条件，再做试验。
