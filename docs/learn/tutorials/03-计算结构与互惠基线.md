## 2. 建每个账号的度与强度

```python
con.execute("""CREATE TEMP TABLE node_stats AS
WITH incoming AS (SELECT dst AS id,count(*) AS kin,sum(weight) AS sin FROM e GROUP BY 1),
outgoing AS (SELECT src AS id,count(*) AS kout,sum(weight) AS sout FROM e GROUP BY 1),
nodes AS (SELECT src AS id FROM e UNION SELECT dst FROM e)
SELECT n.id,coalesce(kin,0) AS kin,coalesce(kout,0) AS kout,
       coalesce(sin,0) AS sin,coalesce(sout,0) AS sout
FROM nodes n LEFT JOIN incoming i USING(id) LEFT JOIN outgoing o USING(id)""")
con.sql('SELECT count(*) AS n,sum(kin) AS indegrees,sum(kout) AS outdegrees,sum(sin) AS instrength,sum(sout) AS outstrength FROM node_stats').show()
con.sql('SELECT kin,count(*) AS agents FROM node_stats GROUP BY 1 ORDER BY 1').show()
con.sql('SELECT median(kin),median(kout),max(kin),max(kout) FROM node_stats').show()
```

入度和出度总和应都等于二值边数；强度总和应都等于事件权重。这里节点全集是至少参与一条有效边的端点。它不包括所有从未被评论的发帖账号，报告时必须说明。

CCDF可把每个度值对应的频数累加。先输出表，再决定是否画图。不要先拟合幂律直线；若要拟合，按[重尾与幂律](../concepts/重尾与幂律.md)做尾部检验与模型比较。

## 3. 计算边互惠

```python
con.sql("""SELECT count(*) AS directed_edges,
 count(*) FILTER (WHERE b.src IS NOT NULL) AS reciprocated_edges,
 count(*) FILTER (WHERE b.src IS NOT NULL)*1.0/nullif(count(*),0) AS edge_reciprocity
 FROM e a LEFT JOIN e b ON a.src=b.dst AND a.dst=b.src""").show()
```

每个双向账号对贡献两条互惠有向边。manifest使用同一公式。对`reply_edges.parquet`重复计算时，新开连接或换view名。两张图的差异来自关系定义，不能把较大的那个选作“更真实”的唯一结果。

## 4. 计算一个非负量的Gini

以下例子是“边端点账号的入强度不均”，不是karma不均。

```python
con.sql("""WITH ranked AS (
 SELECT sin AS x,row_number() OVER(ORDER BY sin,id) AS r,count(*) OVER() AS n
 FROM node_stats)
SELECT CASE WHEN sum(x)>0 THEN
 2.0*sum(r*x)/(max(n)*sum(x))-(max(n)+1.0)/max(n) END AS gini
FROM ranked""").show()
```

同时报告零入强度比例和头部占比。普通Gini不适合含负数的karma，不在本教程中对它直接计算。

## 5. 图算法是后续独立步骤

聚类、分量、k-core需要稀疏图算法包。当前核查环境没有NetworkX/igraph，本次没有为此更改公共环境。需要时由管理员或个人隔离环境安装，并在受控月窗/子图上验证内存。

实施顺序是：先报告N/E和边类型，再分量，再聚类和核心。路径采用LSCC或抽样源节点，不生成全对距离矩阵。若无向投影算k-core，写清丢失方向。随机基线写清保留度还是只保留密度，不能只交一张“漂亮的网络图”。
