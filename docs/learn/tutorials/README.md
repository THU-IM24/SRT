**2026-10-30 更新说明**：教程已按当前 `srt2` 环境、公开 Moltbook 快照、只读数据边界和现有分析脚本重新整理。旧的 conda 路径、未核实的原始子路径和“教程写好就等于分析完成”的表述已移除。

## 主线教程

1. 【必读】[01 核查环境与数据边界](01-核查环境与数据边界.md)：确认快照、字段、资源和只读审计。
2. 【必读】[02 从 Parquet 建立事件表与两种网络](02-从Parquet建立事件表与两种网络.md)：建立事件表、主网络和直接回复网络。
3. 【选读】[03 计算结构与互惠基线](03-计算结构与互惠基线.md)：计算度、强度、集中程度和静态互惠。
4. 【必读】[04 核对回复树与帖主回应](04-核对回复树与帖主回应.md)：区分帖主出现、直接回应和有序往返。
5. 【选读】[05 按时间窗比较对话持续](05-按时间窗比较对话持续.md)：建立回应机会表，处理随访和右删失。
6. 【必读】[06 抽样与人工编码对话功能](06-抽样与人工编码对话功能.md)：从结构回应走向内容承接和双人编码。
7. 【选读】[07 从指标到研究检验](07-从指标到研究检验.md)：固定主问题、竞争解释和停止条件。
8. 【选读】[08 复现与小规模机制实验设计](08-复现与小规模机制实验设计.md)：区分复现、方法迁移和离线机制实验。

## 验证边界

- `src/analysis/` 的合成测试和低内存脚本可在服务器按01–02运行；不要把合成测试当成真实效果证据。
- 本轮文档更新与检查见[教程更新与验证记录（2026-10-30）](../../notes/教程验证记录-2026-10-30.md)；过去的服务器审计与9月网络结果见[教程验证记录（2026-10-23）](../../notes/教程验证记录-2026-10-23.md)和[当前数据核查](../../notes/当前数据核查-2026-10-23.md)，它们是历史证据，不是本次自动重跑。
- 全量祖先重建、正式回应机会表、生存模型、人工双标、正式回归、零模型和机制实验仍需独立执行；教程中的设计和代码片段不替代结果。
- 原始数据、正文、账号清单、派生事件表和私有作者简介表均不进入公开仓库。

代码入口见[分析代码说明](../../../src/analysis/README.md)，研究设计见[下一步研究计划](../../notes/下一步研究计划.md)。
