# 07 从指标到研究检验

**目标**：把“多算几个指标”变成可以证伪的研究问题，并能说明结果不支持假设时怎么办。
**先读**：[结构与功能](../concepts/结构与功能.md)、[相关与回归](../concepts/相关与回归.md)、[因果识别](../concepts/因果识别.md)。

## 1. 固定一个主要问题

示例：在同月、同主题、相似活动量与随访时长下，前期结构位置是否与后期父子消息承接率有关？这是候选设计，不是已确认空白，也不是已获得的结果。

自变量应来自结果之前。结果是人工可验证的承接或严格往返。别用当期回复数定义“核心”，再用同一批回复证明核心更会对话。

## 2. 先列相互竞争的解释

| 观察 | 可能解释 | 可以怎样区分 |
|---|---|---|
| 核心回复更多 | 活动多、曝光多、关系稳定 | 控制前期活动；等账号权重；观察后期窗口 |
| 深链更连贯 | 本来是技术问答、幸存选择 | 同主题同规模匹配；同时报告进入深链机会 |
| 低互惠 | 没有互动动机、没看见、账号已停止运行 | 只报告可识别关联；引入活跃机会代理及敏感性 |
| 后期回楼变多 | 规则改变、存活者选择、采集改善 | 同账号面板；固定新入组；覆盖分层 |

没有曝光日志时，不能把“其他地方还在发帖”称为真实看见了本线程。它只是一个可观察的活跃机会代理，而且用后续活跃筛选还可能引入选择偏差，须作为敏感性结果。

## 3. 写最小分析表

每行一个候选机会，含前期指标、月/社区/语言、线程特征、覆盖状态、结果、权重、随访时长。每个字段写来源时间。最终karma和最终线程规模可以用于事后描述，不能未经说明当作事前控制。

先做分层比例，再做简洁模型。输出预测概率差与区间，比只给回归系数更易解释。聚类层级考虑线程、作者或账号对。

## 4. 指定零模型与负对照

结构同质性采用保留度与机会条件的连边交换。内容承接采用同主题父消息错配。若对照保留了所有真正机制，它也可能过强；若破坏了语言和时间，它可能过弱。写清要排除的竞争解释。

对模型一次只增加一组控制，查看主要估计怎样变化。不要把数百个规格跑完只汇报显著的一种。

## 5. 三种结果都能写

如果结构—功能正相关，检查能否被活动或模板解释。如果不相关，检查测量精度和覆盖后再讨论结构不足以预测功能。如果仅少数层相关，报告边界并用独立后期样本验证。结果与预期相反时保留，不临时换主要指标。

## 6. 什么时候停止扩展

优先完成可信基线、人工验证和一个主检验。若人工一致性始终不足，收缩到可稳定区分的功能。若真实父子不优于错配，先研究测量失效。若候选贡献已被论文覆盖，改成独立复现或重定问题，不能靠换名词维持“原创”。
