# 07 从指标到研究检验

**版本**：2026-10-30 复核版
**目标**：把“多算几个指标”变成可证伪、可停下来的研究问题，并说明结果不支持预期时怎么办。
**先读**：[结构与功能](../concepts/结构与功能.md)、[相关与回归](../concepts/相关与回归.md)、[因果识别](../concepts/因果识别.md)。

> 当前仓库已完成的是环境、数据边界和部分结构基线；本页的主检验、回归、零模型和推断仍是待执行设计。写出模型不等于得到结果。

## 1. 固定一个主要问题

候选问题：在同月、同主题、相似活动量与随访时长下，前期结构位置是否与后期父子消息承接率有关？这是候选观察性设计，不是已确认空白，也不是已获得的结果。

自变量必须来自结果之前。结果优先用06的人工承接或04的严格往返；不能用当期回复数定义“核心”，再用同一批回复证明核心更会对话。

## 2. 写相互竞争的解释

| 观察 | 可能解释 | 可以怎样区分 |
|---|---|---|
| 核心回复更多 | 活动多、曝光多、关系稳定 | 控制前期活动；使用后期窗口和等账号权重 |
| 深链更连贯 | 技术问答、幸存选择 | 同主题同规模匹配；报告进入深链机会 |
| 低互惠 | 没动机、未看见、账号停止、采集缺失 | 只报告可识别关联；做活跃机会和覆盖敏感性 |
| 后期回楼变多 | 规则改变、存活者选择、采集改善 | 同账号面板；固定新入组；分层比较 |

没有曝光日志时，不能把“其他地方还在发帖”叫作真实看见了线程；它只是可观察的活跃机会代理，并可能引入选择偏差。

## 3. 写最小分析表

每行一个候选机会，至少含：前期指标、月份/社区/语言、线程特征、覆盖状态、结果、抽样权重和随访时长。每个字段都标来源时间。最终 karma 或最终线程规模是事后变量，未经说明不能当作事前控制。

先做分层比例和资格漏斗，再做简洁模型。输出预测概率差或标准化差异及区间，比只给回归系数更容易解释。聚类层级考虑线程、作者和账号对；抽样权重与缺失处理事先写入分析合同。

## 4. 指定零模型与负对照

结构同质性可用保留度序列和机会条件的连边交换；内容承接可用同主题父消息错配。对照若保留真正机制，可能过强；若破坏语言和时间，可能过弱。每个对照都写清要排除的竞争解释。

模型一次只增加一组控制，记录主要估计怎样变化。不要跑数百个规格只报告显著的一种，也不要把稳健性表当成事后挑结果的许可。

## 5. 三种结果都能写

- 若结构—功能正相关：检查是否被活动、模板、语言或覆盖解释。
- 若不相关：先检查测量精度、资格筛选、功效和覆盖，再讨论结构不足以预测功能。
- 若仅少数层相关：报告边界，用独立后期样本验证。
- 若结果与预期相反：保留原结果，不临时更换主要指标。

观察性关联、独立复现、机制实验和因果结论要使用不同措辞，不能因为模型复杂就跨越识别边界。

## 6. 什么时候停止扩展

优先完成可信基线、人工验证和一个主检验。若人工一致性不足，收缩到稳定可区分的功能；若真实父子不优于错配，先研究测量失效；若候选贡献已被已有论文覆盖，改做独立复现或重定问题，不能只换名词维持“原创”。

具体里程碑、分工与退出条件见[下一步研究计划](../../notes/下一步研究计划.md)。
