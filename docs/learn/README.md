# 学习路线

**从[必读路线（约2小时）](必读路线.md)开始，共15页（11个概念页＋4个教程）；本页其余内容作为分工练习参考。**

这套资料面向第一次接触社会网络分析和内容编码的组员。集体机器行为已并入[结构与功能](concepts/结构与功能.md#集体机器行为)，内容编码并入[编码一致性](concepts/编码一致性.md#内容编码单位标签与手册)，深宽标度并入[回复树](concepts/回复树.md#选读讨论树的深宽标度)的选读小节。语义工具查[文本嵌入中的余弦相似度](concepts/文本嵌入.md#余弦相似度)，登录认证查[SSH中的公钥与私钥](concepts/SSH.md#公钥与私钥)。路径与不可达点对查[路径长度中的全局效率](concepts/路径长度.md#全局效率)，主题分散与身份一致的区别查[社区语义一致性中的主题熵](concepts/社区语义一致性.md#主题熵)。先完成小任务，再回到论文，不要求先读完所有概念页。

## 上机参考：数据与结构角色先跑通

1. [核查环境与数据边界](tutorials/01-核查环境与数据边界.md)：理解快照、字段、内存和审计。
2. [建立事件表与两种网络](tutorials/02-从Parquet建立事件表与两种网络.md)：手算边，跑语义检查，再跑月窗。
3. [计算结构与互惠基线](tutorials/03-计算结构与互惠基线.md)：区分度/强度，核对互惠与节点全集。
4. [核对回复树与帖主回应](tutorials/04-核对回复树与帖主回应.md)：理解帖主出现、严格回应和有序往返。

读到这里，应能解释“很多连边”和“发生对话”的区别。不要把互惠数值较大直接理解成更有社会性。

## 按分工继续练习

- 时间与网络：读[05时序与删失](tutorials/05-按时间窗比较对话持续.md)、连通分量、小世界、零模型与核心。
- 内容与人工编码：读[06抽样与编码](tutorials/06-抽样与人工编码对话功能.md)、[语义承接](concepts/语义承接.md)（含[论证关系选读](concepts/语义承接.md#论证关系)）、编码一致性。
- 研究综合：读[07从指标到检验](tutorials/07-从指标到研究检验.md)、因果识别、模拟有效性。
- 有余力的实验：读[08复现与实验](tutorials/08-复现与小规模机制实验设计.md)。没有选择路线前不部署大模型。

## 第三轮：回到四篇论文

[四篇论文概念对照表](../papers/四篇论文概念对照表.md)逐项给出原文章节、概念页、教程和实施边界。建议01看结构方法，02看有效性，03看功能操作化，04必须看v2和附录中的替代解释。
