# 学习路线

**从[必读路线](必读路线.md)开始。** 这套资料面向第一次接触社会网络分析和内容编码的组员；教程已按2026-10-30的服务器约定和公开数据边界复核。

先完成上机小任务，再回到论文，不要求先读完所有概念页。当前入口是：

1. [01 核查环境与数据边界](tutorials/01-核查环境与数据边界.md)：确认 `~/venv-srt`、快照、字段、资源限制和只读审计。
2. [02 建立事件表与两种网络](tutorials/02-从Parquet建立事件表与两种网络.md)：手算边，跑合成测试和月窗，理解父节点不能随窗口截断。
3. [03 计算结构与互惠基线](tutorials/03-计算结构与互惠基线.md)：区分度/强度、二值边/事件权重、主网络/回复网络。
4. [04 核对回复树与帖主回应](tutorials/04-核对回复树与帖主回应.md)：区分帖主出现、严格回应和有序往返。

读到这里，应能解释“很多连边”和“发生对话”的区别。不要把静态互惠直接理解成语义承接或社会性。

## 按分工继续练习

- **时间与网络**：读[05时序与删失](tutorials/05-按时间窗比较对话持续.md)、连通分量、小世界、零模型与核心。
- **内容与人工编码**：读[06抽样与编码](tutorials/06-抽样与人工编码对话功能.md)、[语义承接](concepts/语义承接.md)（含论证关系选读）、编码一致性。
- **研究综合**：读[07从指标到检验](tutorials/07-从指标到研究检验.md)、因果识别和模拟有效性。
- **离线实验**：读[08复现与实验](tutorials/08-复现与小规模机制实验设计.md)。没有明确任务、预算和判定规则前，不部署大模型。
