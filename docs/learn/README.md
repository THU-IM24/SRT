# learn —— 学习资料

给刚接触本项目方法的同学看。分两类：

- **概念页**（`concepts/`）：一页只讲一个概念，文件名就是概念名，例如 `度分布.md`。
- **教程页**（`tutorials/`）：一步一步带着做一件事，例如“从 Parquet 建评论网络”。

教程里出现术语时，链接到对应概念页，方便随时查，例如 `[度分布](../concepts/度分布.md)`。

## 概念页模板

```markdown
# 度分布

**一句话**：……

**怎么算**：……

**在本项目里**：……

**相关概念**：[互惠性](互惠性.md)
```
