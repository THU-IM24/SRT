# 不确定性

**一句话**：不确定性表示我们的结果会因抽样、测量误差或合理的分析选择而改变多少。

## 三个来源

- **抽样不确定性**：只看了一部分材料；
- **测量不确定性**：漏采、错接父消息或人工编码不一致；
- **模型不确定性**：换一个合理的定义、窗口或基线，结果可能不同。

一个置信区间通常只覆盖其中一部分，不是对所有未知问题的保证。

## 为什么不能逐行当独立样本

同一线程的评论、同一账号的多次发言往往相互相关。逐行bootstrap会让样本看起来比实际更大。可以按线程、账号或账号对重抽，具体取决于研究单位。

## p值和效应量

样本很大时，极小差异也可能显著。除了$p$值，还要报告差值、比例或预测概率及其区间；多次检验要区分预先指定的主问题和探索性分析。

## 只需记住

一个结果“稳定”只说明在给定替代定义下相近，不等于因果成立；一个结果“不显著”也不等于两者完全相同。
