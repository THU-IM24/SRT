# 不确定性

**一句话**：不确定性描述估计值对抽样、测量误差和建模选择有多敏感。

## 三种来源
抽样误差来自只看一部分材料。测量误差来自漏采、错接父节点和编码错误。模型不确定性来自不同合理定义与过滤规则。置信区间通常只覆盖其中一部分，不是所有未知的保证。

## 依赖与自助法
同线程评论、同账号重复发言高度相关。按评论逐行bootstrap会夸大独立信息。按线程重抽，或用作者/线程聚类标准误；涉及账号对时考虑二人组依赖。先说明分析单位和相关结构。

## p值与效应量
样本巨大时很小差异也会显著。报告比例差、风险比或预测概率与区间，并判断实际意义。多次检验应区分预先指定的主检验与探索，必要时控制FDR，不能只挑显著月份。

## 本项目交付
每个主结果都有分母、缺失率、区间和至少一个合理替代定义。用未过滤、平台标记过滤、模板过滤以及不同观察窗口做敏感性表。稳定不代表因果，反复不显著也不代表两者完全相同。
