# 聚类系数

**一句话**：聚类系数衡量“一个人的朋友之间，彼此也认识多少”。

## 直观例子

A认识B和C。如果B也认识C，就形成一个三角形，说明A的邻居很紧密；如果B和C完全不认识，A的邻居就比较分散。

## 公式

节点 $i$ 有 $k_i$ 个邻居，邻居之间实际有 $e_i$ 条边，则局部聚类系数为：

$$
C_i = \frac{2e_i}{k_i(k_i-1)}
$$


分子乘2，是因为无向边连接两个邻居。$k_i<2$ 时没有可能形成三角形，应事先说明记为0还是缺失。全网聚类系数可以取所有 $C_i$ 的平均，也可以使用传递性；两者的加权方式不同。

## 一个小例子

A的两个邻居B、C：

- B和C相连：$C_A=1$；
- B和C不相连：$C_A=0$。

聚类高只说明关系闭合得多，不能说明这些关系一定发生过持续对话。

## 不要混淆

把有向图直接变成无向图，会丢掉“谁指向谁”的信息。三个人互相评论过，能形成高聚类；但这不等于他们在同一线程中轮流回应。
