# 聚类系数

**一句话**：聚类系数衡量一个节点的邻居之间有多常互相连接。

## 无向局部定义
节点 i 有 k_i 个邻居，邻居之间实际存在 e_i 条边时，C_i=2e_i/[k_i(k_i−1)]。k_i<2 时必须交代记为 0 还是缺失。平均局部聚类是各节点 C_i 的平均；全局传递性按闭合三元组与连通三元组计算。两者权重不同。

## 有向情形
有向三角形可以是循环、传递或带双向边的结构。01 使用 Fagiolo 的有向聚类作为补充。复现时写明公式和实现。不能把无向三角形数量直接解释成有向反馈。

## 一个反例
A、B、C 都互相评论过，聚类很高。但如果评论来自相隔数月的广告模板，就没有证明发生持续讨论。聚类测结构闭合，回复链测按时间发生的接续。

## 本项目怎样比较
先给无向二值投影的入门结果，再与保留节点数、密度或度序列的随机图比较。小图和大图的绝对聚类值不宜直接横比。若只在采样图中计算，要说明抽样会改变三角形。
