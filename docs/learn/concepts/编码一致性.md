# 编码一致性

编码一致性衡量不同编码员依据同一手册，对相同材料能否作出相近判断。内容编码先把文本转成标签，一致性再检查这套规则是否容易被独立执行。本研究以父子消息对判断语义承接，必须保存两人独立结果后再讨论分歧。一致性高说明规则可重复，不保证标签有效或结论正确。

## 内容编码：单位、标签与手册

最小承接单位是父子消息对：父为帖子或父评论，子为当前回复。每条记录保存父消息具体内容点与子回复证据，不能脱离父消息单看回复。

| 维度 | 手册需要固定的规则 |
|---|---|
| 回应功能 | 回答、补充、反驳、澄清、确认、社交、推广、其他；说明单选、多选或主标签规则 |
| 语义承接 | 是／否／不可判；按具体内容对应判断 |
| 新增信息 | 是／否／不可判；针对性确认可承接而不新增 |
| 模板性 | 是／否／不可判；与承接分开判断 |

不同维度可同时存在。若功能允许多选，分别对每个功能的有／无计算一致性，不能把整串标签当作无序的一个类别。

手册包含定义、正反例、边界例、上下文、语言及缺失规则和版本号。最多补两层祖先上下文；两位编码员看到相同材料。小批试标后修订并冻结，改版后重标受影响记录，不混合版本。

## 先独立，再讨论

两位编码员不看对方答案，也尽量不看账号网络位置或真实／错配分组。先保存原始标签并计算一致性，再讨论形成最终共识。共识可用于最终分析，不能冒充独立一致率。

试标与正式验证分别报告，且正式验证材料不再用于调手册或prompt。知道某条来自核心账号可能诱发预期，故只展示必要上下文与匿名编号。

## 一致率和Cohen κ怎样算

简单一致率P_o是两人标签相同的比例。两位编码员标同一批无缺失的名义类别时，Cohen κ=(P_o−P_e)/(1−P_e)，其中P_e为两人各类别边际比例乘积之和。

例如100对材料，两人各有90个“是”、10个“否”，其中“是／是”85、“否／否”5，另外两个分歧格各5。P_o=90%，P_e=0.9×0.9+0.1×0.1=82%，κ≈0.44。高一致率与较低κ可以同时出现，因为类别很不均衡。

若两人全部都选同一类别，P_e=1，κ不可计算，不写成0或1。报告原始混淆矩阵和各类样本量，避免只留下一个系数。

## α、不可判与结果解释

多位编码员或存在缺失时可考虑Krippendorff α，选择适合类别尺度的距离与实现。“不可判”可以作为名义类别纳入κ／α，此时衡量的是包含可判性的一致性；若当作缺失处理，须说明哪些记录仍有足够独立标签，并另报可判性一致与覆盖。不得为提高数字临时删去分歧。

每个维度单独计算，注明双标样本、手册版本、上下文范围和缺失处理。没有适用于所有任务的万能阈值；一致性不足时先定位模糊定义、补边界例或缩小类别，再用新的独立材料核验。

## 选读：大模型辅助编码

先用冻结的独立人工验证集检查模型各类精确率、召回率及不可判情况，不能用模型与单个人相同就证明标签正确。保留错误案例、证据片段和真实／错配检查；正式调用另按项目授权范围执行，本页不运行模型。
