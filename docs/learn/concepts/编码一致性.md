# 编码一致性

**一句话**：编码一致性衡量不同编码员依据同一手册能否对相同材料作出相近判断。

## 先独立，再讨论
两位编码员先在不知道对方答案时标注。保存原始标签，再计算一致性。讨论后的共识标签可以作为最终分析标签，但不能用来计算独立一致性。

## 常用量
简单一致率是相同标签比例。Cohen κ=(P_o−P_e)/(1−P_e)，校正按边际频率偶然相同的部分。多编码员或缺失可考虑Krippendorff α。少数类极稀时，κ与原始一致率可能给不同印象，所以同时报告混淆矩阵和各类样本量。

## 本项目检查
承接与论证分类分开算；“不可判”如何进入分母事先规定。报告试标与正式验证集的结果、手册版本和编码员是否看到网络位置。若知道某条来自核心账号，可能产生确认偏差。

## 不能机械套阈值
一致性低时先定位哪个定义模糊，不是反复讨论直到数字好看。大模型与人工一致也不等于对真实功能的有效性，需要证据片段、负对照和错误案例检查。
