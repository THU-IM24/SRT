# 编码一致性

**一句话**：编码一致性检查不同的人是否能按照同一份规则给文本贴出相近标签。

## 内容编码：单位、标签与手册

先确定一条记录是什么：一条评论、一个父子回复对，还是一整个线程。再写标签定义、正例、反例和“不可判”条件。

例如判断语义承接时，不能只看子回复；必须同时看到父消息，并能指出子回复处理了父消息中的哪个具体内容点。

## 正确流程

1. 两名编码员独立编码同一批材料；
2. 计算一致性；
3. 讨论分歧并修改手册；
4. 冻结规则后再编码正式样本。

不要先一起讨论出答案，再把“共识”当成可靠性证据。

## 一致率和 Cohen's $\kappa$

一致率是简单的相同百分比；$\kappa$ 还扣除了“随机碰巧一致”的部分：

$$
\kappa=\frac{P_o-P_e}{1-P_e},
$$

其中 $P_o$ 是观察到的一致率，$P_e$ 是按双方边际比例计算的偶然一致率。类别极不平衡时，$\kappa$ 可能很低，即使表面一致率很高。

## 只需记住

不可判不能悄悄改成否；多标签、缺失文本和类别极少时，要单独说明分母和指标。模型辅助编码也需要人工抽查，不能把模型输出直接当真值。
