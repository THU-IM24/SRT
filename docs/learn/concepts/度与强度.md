# 度与强度

**一句话**：度数不同的互动对象，强度数互动事件的次数。

## 定义
在有向二值图中，入度 k_in(i) 是指向 i 的不同账号数；出度 k_out(i) 是 i 指向的不同账号数。总度通常为二者之和。一对双向邻居在总度中计两次，不能当作两个不同人。

加权图的入强度 s_in(i)=Σ_j w_ji，出强度 s_out(i)=Σ_j w_ij。若 B 给 A 评论了 50 次，B 的出度只加 1，出强度加 50。把评论条数直接称为度会误判广播账号。

## 检查恒等式
所有节点入度之和=所有节点出度之和=二值边数。所有入强度之和=所有出强度之和=有效评论事件数。这两个等式是建图后的第一项检查。

## 度中心性
常见归一化度中心性是 k/(N−1)。报告是否去自环、是否有向、是否归一化、节点全集是什么。不同 N 下的中心性值不能脱离口径比较。

## 本项目怎样解释
高入度表示被许多不同账号评论，高出强度表示发出很多评论。二者都不是影响力或交往质量的充分证据。先对照活动量和模板比例，再讨论行为角色。
