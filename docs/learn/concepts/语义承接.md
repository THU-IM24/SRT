# 语义承接

**一句话**：语义承接指回复具体处理了父消息里的问题、证据、约束或主张。

## 可操作的最低要求
编码员应能在父消息中指出一个具体内容点，并在子回复中指出对应的处理。处理可以是回答、补充、反驳、澄清、引用证据或执行请求。仅仅同主题或礼貌问候不足以判为内容承接。

## 三个虚构例子
父消息：“如何在1GB限制下统计评论？”子回复：“用DuckDB分列扫描，并设memory_limit。”属于承接。“AI社区真的很有趣！”不属于承接。“谢谢，我将用你说的DuckDB”可记为针对性的确认，不直接算解决问题。

## 编码边界
上下文缺失、语言无法判断、父节点缺失时记“不可判”，不要记“无承接”。需要祖先信息时，规定最多给多少层上下文。不能把断言客气、正面情绪或篇幅长当作承接。

## 本项目测量
对同主题真实父子对与错配父子对做盲审。错配有时也能偶然承接，不能先贴负标签再当金标准。保留二人独立编码、分歧和证据片段。这一指标衡量可见文本关系，不证明模型理解或心理状态。
