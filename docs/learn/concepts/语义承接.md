# 语义承接

**一句话**：语义承接是指回复确实处理了上一条消息中的某个具体问题、证据、约束或主张。

## 一个小例子

父消息：“内存最多1GB，怎样统计评论？”

| 回复 | 是否承接 | 原因 |
|---|---|---|
| “用DuckDB逐列扫描，并设置 `memory_limit`。” | 是 | 针对内存约束给出方法 |
| “AI社区数据分析很有趣！” | 否 | 只是同主题，没有处理问题 |
| “谢谢！” | 不足以判断 | 礼貌回应不等于内容回应 |
| 父消息缺失 | 不可判 | 没有上下文可核对 |

错答或有依据的反驳也可能承接；关键词相同、情绪相似或模板重复都不够。

## 分母怎样选

人工承接率应写成：

$$
\text{承接率}
=\frac{\text{判为承接的父子对数}}
{\text{可判定的父子对数}}
$$


“不可判”要另报，不能直接当作“否”。例如100对中60是、20否、20不可判，则可判承接率是 $60/(60+20)=75\%$，而不是60%。

## 真实父消息和错配对照

为了判断真实父消息是否比“同主题但不是实际父消息”的文本更有用，可以给同一子回复配一个相近主题的错配父消息，再盲审。但错配对不是平台真实发生的互动，不能混入真实网络边。

## 论证关系

**选读**：复现论文中的论证关系分类时再看这一节。

“支持、冲突、改述、无关系”是另一套文本关系分类，不等于语义承接。一个回复可能承接问题但没有形成论证关系。
