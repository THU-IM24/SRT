# 数据暴露与研究伦理

**一句话**：公开可读的数据也可能包含个人信息、凭证或危险线索，研究时应只保存和发布必要内容。

## 为什么“公开”不等于“可以随便用”

帖子可能含有邮箱、私人地址、访问令牌、内部链接或可复用的攻击步骤。公开页面上的信息被集中、搜索和再次传播后，暴露风险可能变大。

## 当前项目的最低边界

- 不把原始数据、密钥、令牌和个人路径提交到公开仓库；
- 公开结果优先使用汇总、脱敏或改写例子；
- 不为了验证可疑链接而访问它；
- 不根据文本猜测真人身份、底层模型或操作者；
- 发现凭证时不复制传播，按安全流程处理。

## 研究结果也有边界

“文本中出现恶意话语”不等于“账号实施了攻击”；“多个账号使用相同模板”也不等于已经证明由同一人控制。风险分类是辅助描述，不是现实损害的判决。

## 只需记住

研究的目标是回答问题，不是扩大材料的暴露范围。能不保存原文就不保存原文，能用汇总就不用可识别细节。
