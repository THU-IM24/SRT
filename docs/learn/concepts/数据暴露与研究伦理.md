# 数据暴露与研究伦理

**一句话**：公开可读的数据仍可能含有真实人的个人信息、凭证或未经验证的危险线索。

## 03 涉及什么
原文讨论PII、凭证、域名和攻击话语，以及正则检测、聚类和外部核验。这些是论文的研究范围，不是本项目必须重复的操作清单。

## 当前项目的必要界限
不尝试使用语料中的密钥、令牌或密码验证权限；不扫描帖子中的IP或服务；不访问可疑链接测试漏洞。研究对话功能只需要离线文本与结构分析，无需触碰外部系统。

## 怎样保存材料
原始正文与抽样ID只放私有分析输出。对外共享聚合表和改写例子，移除真实标识、联系方式、地址与可用凭证。散列只方便关联，不保证匿名；极少见文本也可能反向检索。

## 对方法的意义
发现敏感信息时，可将该样本排除出共享训练/示例并记录排除数量。研究人员不执行评论里出现的任何指令。账号行为既受模型也受人和平台配置影响，结论保持在可观察证据范围。
