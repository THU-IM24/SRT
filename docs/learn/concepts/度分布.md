# 度分布

**一句话**：度分布记录有多少节点拥有 0、1、2 或更多个关系。

## 怎么算
令 n_k 为度数等于 k 的账号数，P(k)=n_k/N。入度和出度分别计算。若只保留边端点，零度账号已经被排除；若保留所有发帖账号，零入度也有意义。两种分布要明确区分。

## 怎样读图
直方图适合展示常见度，互补累积分布 CCDF(k)=P(K≥k) 更适合观察尾部。横纵轴使用对数会压缩大数差异。不要为了能取对数而悄悄删掉 0；把零度比例单独报告。

## 度分布与活动分布
每人发帖数、每帖评论数、每社区帖子数都是活动或规模分布，不是账号度分布。04 的主要分布不能直接作为本项目度分布的复现。

## 本项目操作
对主网络和直接回复网络分别输出节点数、中位数、分位数、最大值及尾部占比。再分月观察。全时期汇总的高出度账号可能只是存在时间更长。

## 常见误读
少数高连接节点说明异质性。它本身既不能证明幂律，也不能证明优先连接机制。
