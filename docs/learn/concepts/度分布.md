# 度分布

**一句话**：度分布告诉我们，网络中有多少节点分别连接了0个、1个、2个或更多对象。

## 例子

如果5个账号的出度是 $0,1,1,2,6$，那么度分布就是：0度有1个账号，1度有2个，2度有1个，6度有1个。

它回答的是“连接数量怎样分散”，不是“某个账号为什么受欢迎”。

## 怎样读图

横轴是度数，纵轴是账号数量或比例。若少数账号度数极高、很多账号度数很低，分布会有长尾。应同时看中位数、分位数和最大值，不能只看平均数。

## 不要混淆

发帖多、评论多、连接对象多是三个不同变量。把互动次数当成度，会把活动量误当成连接广度。度分布有长尾，也不自动说明它服从幂律。

## 只需记住

先画分布和分位数；只有在尾部样本足够时，才进一步拟合幂律或其他分布。
