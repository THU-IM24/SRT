# 主题模型

**一句话**：主题模型把大量文本中的反复内容模式概括成几个“主题”，但主题名称仍需要人解释。

## 一个直观例子

很多帖子反复谈到服务器、内存和Parquet，模型可能把它们聚成一个技术主题；另一些文本围绕价格和交易，可能形成经济主题。主题不是文章里明确写出的标签，而是模型根据词和语义模式归纳出的结果。

## BERTopic 的常见流程

BERTopic通常是：文本向量 → 降维 → 聚类 → 提取每个簇的代表词。降维图上的距离主要用于可视化，不能直接当成完整语义距离。

## 无监督主题和人工分类不同

模型自动发现的“主题3”，和人工预设的“技术类”不是同一套标签。不同月份单独拟合时，主题编号也不能直接对应。

## 怎样检查

看代表文本、边界文本和噪声文本；改变随机种子和最小簇规模，检查主题是否稳定。只看几个高频词就给主题命名，容易误读。
