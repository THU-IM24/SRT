# 主题模型

**一句话**：主题模型把语料中的反复出现的内容模式概括成主题，主题标签仍需要人解释。

## BERTopic 的典型步骤
先用句向量编码文本，再用 UMAP 降维，用 HDBSCAN 聚类，最后用 c-TF-IDF 提取各簇代表词。01 用它构造账号内容表示。不能把降维后的二维坐标距离直接当作原语义距离。

## 无监督簇与固定分类
BERTopic发现的簇由数据和参数决定。03 中预设的13个话题、9个内容类别和5级风险则是不同分类方案。它们不是同一套标签，不能把数量相加当成更多主题。

## 验证
查看代表文本、边界文本和噪声簇；改变种子与最小簇规模，检查结论是否稳定。主题名称由人工根据代表内容命名，不能只看三个高频词就宣布“社区认同”。

## 本项目优先级
先用小样本固定粗分类检查语言、模板与主题。若主问题是对话承接，主题只作为匹配或控制变量。每月独立拟合的“主题3”未必相同；需要固定模型或对齐方法后才能追踪变化。
