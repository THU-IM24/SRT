# 模板重复

**一句话**：模板重复指多个输出复用相同或近似文本形式，不必然表示内容无用。

## 精确与近似
精确重复先规范换行、Unicode与空白，再对文本做哈希。近似重复可用字符n-gram、MinHash或向量检索提出候选。不要把所有数字、代码和实体删掉，否则关键不同的技术答案会变成“同一模板”。

## 两种重复率
事件重复率衡量评论中有多少复用既有文本。线程唯一内容比=不同规范化文本数/评论数。作者集中度则是另一个量。04 同时用内容与作者比例过滤，但不应把它们视为相同现象。

## 关系到功能
“谢谢”重复很多但可能正确完成确认；不同措辞的长篇回答也可能毫无针对性。模板性与语义承接应各自编码，允许同时为是。先提出阈值并做敏感性分析，不为得到好看结果临时调阈值。

## 本项目用法
先保留未过滤基线，再分别应用平台spam标记、精确重复阈值、作者集中阈值，报告删掉多少帖子和多少评论。04 中很少帖子承载很多评论，提醒我们不能只报删帖比例。
