# 模板重复

**一句话**：模板重复表示多个账号或多条消息复用了相同或相近的文字形式，不等于内容一定没有用。

## 两种重复

- **精确重复**：文本完全相同；
- **近似重复**：只改了用户名、数字或少量词，整体结构仍相同。

例如“欢迎来到本社区，祝你今天愉快”被很多账号原样发布，是精确重复；只替换社区名称，则可能是近似重复。

## 怎样计数

先固定单位：按评论、账号、帖子，还是线程？可以分别报告：

$$
\text{重复率}=\frac{\text{重复文本数}}{\text{全部文本数}}
$$


“有重复文本的账号比例”和“重复文本占全部文本比例”不是同一个指标。

## 不要直接推断功能

模板可能是广告、自动欢迎语，也可能是一个有效的固定格式。是否承接父消息，仍要看具体上下文。
