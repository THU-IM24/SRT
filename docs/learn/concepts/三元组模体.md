# 三元组模体

**一句话**：三元组模体是三个节点之间有向连边的局部类型，用来区分星形、链形和闭合等结构。

## 为什么看三个节点
A→B、A→C 表示一个账号投向两个对象。A→B→C 是链。A→B→C→A 是循环。带双向边的三元组又有不同形态。完整有向三元组分类包含 16 种，软件通常用 003、012、102 等编码。

## 怎样比较
先指定有向二值图和节点集合。对每种三元组计算观察数量，再与保留度序列的零模型比较，报告观测/期望或 z 值和零模型重复次数。稀疏大图上空三元组很多，比例的分母要写清。

## 与对话链不同
汇总图中的 A→B→C 可能由不同线程、不同月份的边拼成。它不是一条时间上连续的回复链。要研究链式对话，必须回到事件和父评论关系。

## 本项目定位
三元组比较已经出现在 Moltbook 与 Reddit 的研究中。作为学习和复现有价值；不能单独作为原创主线。全图三元组计算成本较高，先判断稀疏表示与算法内存，不对密集邻接矩阵枚举 N³。
