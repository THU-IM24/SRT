# 三元组模体

**一句话**：三元组模体把三个节点之间的连接方式分类，用来观察网络中常见的局部形状。

## 三个节点能形成什么

- $A\to B$、$A\to C$：星形；
- $A\to B\to C$：链形；
- $A\to B$、$B\to C$、$C\to A$：循环；
- 三条边都存在：闭合结构。

有向边的方向不同，模体类型也不同；常见软件会用 `003`、`012`、`102` 等代码表示类型。

## 怎样比较

先统计真实网络中每种模体出现多少，再与一个保留重要特征的零模型比较。稀疏大图里，三节点组合很多，必须说明分母和节点集合。

## 不要混淆

汇总网络中的 $A\to B\to C$ 可能来自不同线程、不同月份。它说明三条边同时存在，不等于真的发生过一条连续的回复链。
