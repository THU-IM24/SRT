# 右删失

**一句话**：右删失表示“观察结束时事件还没出现”，但我们不知道之后会不会出现。

## 一个生活例子

10月7日9:00发布的评论，到9:12时还没有回复；如果数据只观察到9:12，我们只能说“至少12分钟没有看到回复”，不能说“24小时内不会回复”。

## 三种情况要分开

| 情况 | 能否判定24小时未回应 |
|---|---|
| 完整观察24小时且没有回复 | 可以 |
| 只观察了12小时 | 不可以，随访不足 |
| 时间够24小时但数据缺失 | 不可以，覆盖不可靠 |

把后两种都当成“未回应”，会把采集问题误当成行为结果。

## 固定窗口怎么做

先定义事件，例如“首次直接回复”；再定义可靠观察终点 $C$。起点为 $t_0$、窗口为 $h$ 的记录，只有满足：

$$
t_0+h\le C
$$

才有资格进入完整 $h$ 小时分析。窗口内出现目标回复算成功，窗口外出现不算该窗口成功。

## 选读：生存分析

生存分析可以保留不同长度的随访，把未见事件的记录标为删失。但它仍需要说明观察终点和缺失机制，不能靠公式自动修复漏采。
