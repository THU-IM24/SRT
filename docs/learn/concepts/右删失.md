# 右删失

**一句话**：右删失指观察结束时尚未看到结果，不能据此断定结果永远不会发生。

## 快照中的例子
10月7日09:00创建的评论，到09:12快照结束只观察了12分钟。它没获回复，不能直接作为“24小时内无人回复”的样本。每条记录的可用随访时间可能不同，还受采集刷新方式影响。

## 两种处理
固定随访：只纳入创建时间早于可靠观察终点减24小时的记录，再检查24小时内是否被回复。生存分析：保留不同随访时长，将未见事件的记录在可靠终点删失。两者都需要明确可靠终点，不能只把最大created_at当成完全覆盖保证。

## 常见错误
删除所有没获回复的评论，只对获回复者求平均等待时间，会产生选择偏差。把所有未回复当成无限等待，也不合适。快照中“最后活动”不等于账号退出平台。

## 本项目怎样报告
固定窗结果作为易解释基线，24小时与7天分别列资格分母。敏感性分析让可靠终点向前移动1天、7天。缺失父评论带来的不可观测不是普通行政删失，应另列覆盖问题。
