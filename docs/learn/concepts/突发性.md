# 突发性

**一句话**：突发性表示行为不是均匀发生，而是短时间集中出现，随后出现较长空档。

## 一个例子

账号A在10分钟内连续评论20条，之后两天没有活动。账号B每隔两小时评论一次。两者总评论数可能相同，但A更有突发性。

## 怎么描述

把同一账号相邻两次活动的时间差记为 $\Delta t$，再看这些间隔的分布。如果短间隔和长空档同时很多，通常比均匀活动更像突发过程。也可以把观察时间切成固定窗口，比较每个窗口的活动量。

## 与泊松过程比较

泊松过程假设事件以稳定平均速率独立发生。真实社交活动常受到回复链、提醒、模板和平台推荐影响，因此偏离泊松只能说明“不像这个简单基线”，不能直接说明存在某一种心理或算法机制。

## 只需记住

突发性描述的是**时间节奏**，不是活动总量，也不是“机器人”或“人类”的身份证明。要区分短时集中和快照覆盖缺口，还需检查数据时间边界。
