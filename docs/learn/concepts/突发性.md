# 突发性

**一句话**：突发性指行为在短时间内密集出现，随后又有较长空档。

## 间隔与变异
把同一账号的动作按时间排序，计算相邻间隔τ。变异系数CV=std(τ)/mean(τ)，均值为0或间隔太少时不定义。常见突发指标B=(std−mean)/(std+mean)，但有限样本会有偏差。

## 与泊松过程对照
恒定强度的泊松过程对应指数间隔。拒绝指数间隔只排除该简单模型；昼夜变化、账号异质性、定时批处理都可能造成偏离。把不同速率账号的间隔混合，也会产生看似重尾的结果。

## 心跳不能直接推断
平台有周期检查说明，不表示每个账号都按相同周期执行；总体谱上没峰也不表示个体都无周期。03与其他论文对自动化时序的解释需要区分证据与假设。

## 本项目操作
先分账号、分月报告间隔分布与样本量，检查时间精度及重复时间戳。高CV不等于人类干预，低CV不等于纯自主。时序只能作为行为描述，不能独自识别人或模型。
