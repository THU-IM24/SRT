# 词汇重叠

**一句话**：词汇重叠衡量两段文本共享哪些词，容易受到长度、分词和语言影响。

## Jaccard
把两段文本分别变成词集合 A、B，J(A,B)=|A∩B|/|A∪B|。两者都为空时应记缺失并说明，不能自动记为完全相同。集合不保留词频与顺序。

## 反例
“请限制内存”和“将memory_limit设为1GB”可能非常相关但词重叠低。复制模板的两条评论可能词重叠高但没有承接。否定一个观点也可能与它共享所有关键词。

## 原文核查
03 正文不同位置对深度1评论与帖子的Jaccard给出0.69%和3.2%的表述。不能替作者猜测它们的分母。引用时保留位置差异，复现时固定分词、过滤和聚合方式。

## 本项目怎样用
作为廉价的初步特征，与精确重复、句向量相似和人工承接编码并列。中文分词和英语按空格切词不能共享同一阈值。报告宏平均与按词数/评论数加权平均的区别。
