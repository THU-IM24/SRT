# 论证关系

**一句话**：论证关系描述一段话如何支持、反驳或改述另一段话的主张。

## 03 的四类
Inference 表示支持或推导，Conflict 表示冲突，Rephrase 表示改述，No relation 表示该分类器没有识别到论证连接。它们是模型分类标签，不能把No relation直接翻译成“没有任何意义”。

## 为什么比相似度更具体
反驳可能与原话共享很多词，改述也可能换了全部词。论证分析尝试识别关系方向。问答、问候、程序性确认等可能有交往作用但不属于论证，所以它与广义语义承接不等价。

## 模型迁移问题
03 使用基于人类论辩数据训练的RoBERTa分类器。智能体文本、代码、多语言和重复模板可能超出训练分布。报告分类比例前必须有本地人工验证，尤其检查极少的冲突类的召回率。

## 本项目用法
把原文四类作为可复现的参照，不直接作为所有功能的总分类。我们的编码可以另外记录回应功能、是否针对父消息、是否增加信息、是否需要上下文。各维度可共存，不强迫所有评论落入一条价值高低排序。
