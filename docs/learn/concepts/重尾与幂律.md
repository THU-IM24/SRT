# 重尾与幂律

**一句话**：重尾表示大值仍有明显概率，幂律是对尾部形状更严格的一种模型。

## 公式与尺度
离散幂律通常写作 P(X=x)∝x^(−α)，只在 x≥xmin 的尾部拟合。概率质量函数指数 α 与 CCDF 的尾部指数 α−1 不同，引用图中斜率前先看纵轴。对数正态与截断幂律是不同分布，不能因为都能拟合尾部就称为数学等价。

## 合理的拟合流程
先决定变量和样本，再用最大似然估计 α 与 xmin，报告尾部样本数。通过重新拟合的参数自助法检查拟合优度。再与对数正态、指数、截断幂律比较似然。p 大表示没有足够证据拒绝该模型，不表示模型已被证明。

## 论文里的提醒
01 的出度幂律只落在很小的尾部，不能推广到所有账号。04 v2 对全期每帖评论数提出比纯幂律更合适的备选模型，不能沿用早期版本的“直线就是幂律”。

## 本项目怎样做
先交 CCDF 和分位数，尾部拟合作为有余力时的扩展。报告样本单位、阈值、过滤规则与分月结果。直线回归的 R² 高不能代替分布检验。发现重尾之后，仍须另行检验其生成机制。
