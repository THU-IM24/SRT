# 重尾与幂律

**一句话**：重尾表示“大值并不少见”；幂律是描述这种尾部形状的一种更严格模型。

## 先看直觉

如果大多数账号只有少量连接，但少数账号拥有极多连接，分布就可能有重尾。重尾不等于幂律，也不等于“图上看起来像直线”。

幂律尾部常写成：

$$
P(X=x)\propto x^{-\alpha},\qquad x\ge x_{\min}
$$


只应在选定的尾部 $x\ge x_{\min}$ 上拟合。概率质量函数和累计分布的斜率含义不同，不能混用。

## 正确顺序

1. 先画分布、CCDF和分位数；
2. 再估计尾部起点 $x_{\min}$ 和指数 $\alpha$；
3. 与对数正态、截断幂律等候选分布比较；
4. 报告尾部样本数和不确定性。

对数坐标下的直线回归 $R^2$ 高，不足以证明幂律。

## 只需记住

发现重尾只是描述结果，不等于知道了它的生成机制。优先连接需要另行检验。
