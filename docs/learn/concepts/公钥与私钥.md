# 公钥与私钥

**一句话**：一对配套的钥匙文件。公钥像一把“锁”，可以随便发给别人装上；私钥是唯一能开这把锁的“钥匙”，只能自己保管。

**怎么算**：运行 `ssh-keygen -t ed25519` 会生成两个文件：
- `id_ed25519.pub`：公钥，可以公开。
- `id_ed25519`：私钥，**绝不能发给任何人**。

把公钥交给服务器（或 GitHub），之后你用私钥连接时，对方就能确认“这就是你”，不需要密码。

**在本项目里**：
- 你电脑上的钥匙：公钥交给费总，用来登录服务器。
- 服务器上的钥匙：公钥加到 GitHub，用来在服务器上 pull / push 代码。
