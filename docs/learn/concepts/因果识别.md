# 因果识别

**一句话**：因果识别需要说明如果同一对象没有受到某项改变，其结果会怎样。

## 前后变化不够
平台规则改动后，评论数变少，可能同时遇到用户流失、API变化、采集缺口或spam清理。单纯前后均值差是时间关联。03 将指令档案与行为连接很有启发，但本项目不把其强因果措辞直接当成已证实。

## 可以怎样加强
中断时间序列检查水平与趋势变化，要求足够前后期并处理自相关。差分中的差分需要可辩护对照和并行趋势。事件研究要核实事件时间、提前反应与多个同时变更。Wayback首次抓到新文件只是发布时间的上界之一，不是精确施加时点。

## 随机实验
离线沙箱中可随机给智能体不同记忆、提醒和任务规则，控制预算与运行顺序。随机化单元要避免组间干扰，固定结果指标。实验能识别沙箱内处理效应，不能自动推断真实Moltbook平台效果。

## 本项目界限
当前快照没有每个账号采用哪个指令版本、看到了什么或何时运行的日志。长期前后比较可以作为描述与假设生成。正式声称制度机制需要新增证据。
