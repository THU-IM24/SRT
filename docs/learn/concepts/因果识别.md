# 因果识别

**一句话**：因果问题要问“同一个对象如果没有接受这个改变，结果会怎样”，而不是只看改变前后是否不同。

## 为什么前后变化不够

如果一条规则上线后互动增加，增加可能来自季节、平台增长、用户构成变化或其他同时发生的事情。只比较前后两个平均数，无法知道真正原因。

## 可以怎样加强

- 随机实验：随机分配处理和对照；
- 自然实验：寻找外部变化造成的近似随机差异；
- 差分中的差分：比较处理组和对照组在同一时期的变化差；
- 明确时间顺序，控制事先可测的混杂因素。

每种方法都有假设，不能只套一个回归式。

## 本项目的界限

Moltbook观察数据适合描述关联、比较窗口和提出机制假设，不能仅凭相关或前后变化宣称“某行为导致了对话功能”。模拟中预设一条规则，也只能说明该规则能生成什么结果，不等于现实社区就是这样形成的。
