# 相关与回归

**一句话**：相关描述共同变化，回归在指定模型和控制变量下概括结果与解释变量的关联。

## 选对结果分布
是否回应是二元结果，可用logit或线性概率作基线。评论条数非负且过度离散，可考虑负二项。等待时间有删失，适合生存方法。长尾变量不能只靠取对数便自动解决所有问题。

## 变量时间顺序
预测一条评论被回复时，只用评论出现前可知的信息。快照最终karma、最终线程规模和后续核心位置包含未来信息。若纳入，应称事后描述控制，不能当作事前预测或因果控制。

## 依赖与混杂
同一个账号的很多评论共享配置，同线程共享主题和可见度。加入时间、社区、长度、前期活动等控制只缓解部分差异，不能恢复未观测曝光。固定效应也不消除随时间变化的混杂。

## 本项目报告
先给分层比例和可解释的差异，再给预先指定的小模型。报告样本流、系数对应单位、预测概率区间、聚类层级和敏感性。不要把最复杂模型当作最可信，也不要把系数显著直接写成因果机制。
