# 相关与回归

**一句话**：相关描述两个变量是否一起变化；回归用一个明确模型概括结果与解释变量的关联；二者都不自动等于因果。

## 相关是什么

如果评论数多的帖子通常点赞也多，二者可能正相关。相关只描述共同变化，不说明谁导致谁，也不说明关系是否由第三个变量造成。

## 回归是什么

最简单的线性回归写作：

$$
Y_i=\alpha+\beta X_i+\varepsilon_i
$$


$\beta$ 表示在该模型和控制条件下，$X$ 与 $Y$ 的平均关联变化。它不是脱离设计的“真实影响”。

## 三个检查

1. 结果变量是什么分布，是否需要比例、计数或生存模型；
2. $X$ 是否在时间上先于 $Y$；
3. 账号、线程和月份是否造成相关样本，是否存在混杂。

例如高声誉和高承接同时出现，可能只是高活跃账号既获得更多声誉，也有更多机会收到回复。

## 只需记住

报告系数、区间、样本和分母；不要只报显著性。要讲因果，必须另行说明识别设计。
