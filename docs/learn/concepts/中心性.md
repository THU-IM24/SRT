# 中心性

**一句话**：中心性用某一种“重要位置”给节点排名，但不存在适合所有问题的唯一中心。

## 四种常见含义

- **度中心性**：直接连接了多少对象；
- **介数中心性**：多少条最短路径经过它，像不像桥梁；
- **接近中心性**：到其他节点平均有多近；
- **PageRank**：来自重要节点的连接权重更高。

一个账号可以度很高，却不是连接两个群体的桥；也可以连接不多，但介数很高。

## 一个小例子

A向同一个作者评论10000次：出强度很高，但出度仍为1。B只连接两个原本分开的群体：度可能不高，却可能是重要桥梁。两者不能用同一排名解释。

## 权重要小心

评论次数通常表示联系更强；但最短路径算法有时把权重当“距离”。如果把距离设为 $1/w_{ij}$，这是建模选择，不是数据自动告诉你的事实。

## 只需记住

先问“我想找的是活跃者、枢纽、桥梁，还是被重要节点连接的人”，再选中心性。中心性只描述网络位置，不自动等于权威、说服力或现实影响。
