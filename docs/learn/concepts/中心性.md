# 中心性

**一句话**：中心性衡量节点在某一种结构意义上的位置，不存在适合所有问题的唯一排名。

## 几种常见量
度中心性描述直接相邻对象。介数中心性计算最短路径经过节点的份额。接近中心性关注到其他节点的距离。PageRank 将来自其他节点的连接按其重要性加权。它们的理论含义不同。

## 为什么不能随便用权重
评论次数越大通常表示联系越强，但最短路算法把边权当“距离”时，数值越大会让路径更远。若采用 1/次数 转距离，要明确它只是建模假设。注意力流动也未必沿最短路发生。

## 小例子
一个账号给同一个作者评论 10,000 次，出强度很高，出度仍是 1。另一个账号连接两个原本分离的群体，度不大但介数可能高。两者代表不同角色。

## 本项目优先级
先比较入度、出度、入强度、出强度；把排名与模板重复、帖主回楼、直接回复承接率放在一起看。只有研究跨群体桥接时才考虑介数。大图全量精确介数很贵，可以报告有种子的近似抽样，不能把近似值伪装成精确值。

中心性只描述结构，不自动测量说服力、权威或真实世界影响。
