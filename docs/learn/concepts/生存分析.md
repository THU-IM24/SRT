# 生存分析

**一句话**：生存分析研究“从起点到事件发生要等多久”，并允许一部分记录在事件出现前就停止观察。

## 这里的“生存”是什么

“生存”不是活着，而是目标事件还没有发生。例如：从评论发布开始，到首次直接回复之间的等待时间；尚未得到回复但观察已结束的评论，就是删失记录。

## 看什么

生存函数可以理解为：到时间 $t$ 时，仍未发生目标事件的比例。危险率可以理解为：已经等到 $t$ 时，接下来一小段时间内发生事件的速率。

## 一个小例子

A在1小时后得到回复；B观察了3小时仍无回复；C只观察了30分钟就到快照终点。A有事件时间，B和C都不能简单当作“永远不会回复”；C的随访尤其不足。

## 需要哪些假设

不同对象的随访机会和漏采机制不能差异过大。模型选择也会影响结果。若只想比较完整24小时内是否回应，固定窗口分析往往比复杂生存模型更容易解释。
