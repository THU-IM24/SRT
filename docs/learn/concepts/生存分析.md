# 生存分析

**一句话**：生存分析研究从起点到事件发生的等待时间，并处理部分记录只观察了一段时间的情形。

## 在这里“生存”是什么
起点可以是评论创建，事件可以是第一次直接回复。生存函数S(t)=P(T>t)表示到t还没发生事件；累计回复概率是1−S(t)。危险率是尚未获回复者在下一瞬间得到回复的条件速率。

## 非参数与模型
Kaplan–Meier按风险集与事件更新生存概率。Cox模型估计相对危险，离散时间模型可以按小时建风险集。必须检查独立删失、比例危险等假设；没有这些条件，不能只因软件输出曲线就当作无偏估计。

## 永不回应与回应速度
大量评论可能最终不被回复。把“是否回应”和“有回应时多快”分开，往往比单个半衰期更清楚。中位生存时间只有累计事件超过50%时才有定义，达不到时应报“未达到”。

## 本项目定位
Eziz 已直接研究Moltbook的两部分回复持续性。我们把它作为学习和复现，而不是新提出的方法。若扩展到内容承接，事件定义还要经过人工标注，不能把所有嵌套评论当有效回应。
