# 网络边定义

**一句话**：网络边定义规定“一条评论究竟算作谁指向谁”。边怎么定义，后面的网络指标就会怎么变。

## 同一条评论有三种表示

| 表示 | 一条边表示什么 | 适合回答什么 |
|---|---|---|
| 主网络 | 评论者 $\to$ 帖作者 | 谁参与了谁的帖子 |
| 直接回复网络 | 评论者 $\to$ 实际父消息作者 | 谁直接回复了谁 |
| 回复树 | 父消息 $\to$ 子消息 | 讨论嵌套了几层 |

三种表示不是互相替代的答案。

## 一个虚构例子

A发帖，B评论A；C回复B；A又回复C：

- 主网络：B→A、C→A；A→A是自评，按规则去掉；
- 直接回复网络：B→A、C→B、A→C；
- 回复树：帖子→B→C→A。

同一段讨论，在三种表示里会得到不同的边。

## 还要提前固定什么

节点是谁、箭头方向、是否去自环、同一账号对的多次评论是否合并成一条边、时间窗口如何取，都必须先写清楚。缺少父消息时，不能悄悄把楼中楼改成顶层评论。

## 只需记住

看到“网络中有多少边”时，先追问：**这条边代表什么行为？**
