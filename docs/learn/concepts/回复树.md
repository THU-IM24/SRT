# 回复树

**一句话**：回复树以帖子为根、评论为节点，用父子关系保存一段讨论的嵌套结构。

## 深度、宽度与规模
本项目统一帖子深度为 0，顶层评论为 1。最大深度 d 是从帖子到最深评论的边数。每层评论数的最大值是宽度 w。规模 n 默认是评论数，不含根帖子；必须在公式中写清。

## 从字段到树
parent_id 为空的评论接在帖子上，其余评论接到同帖中的父评论。先检查父节点是否存在、是否属于同帖、是否早于孩子，以及是否出现自指或环。缺父评论不自动改成顶层评论；保留为不可解析状态。

## 结构不等于轮次
A→A→A 的自回复可以产生很深的树。有效往返还要看作者变化与时间顺序。观察上没有嵌套，既可能是真的平，也可能因为楼中楼没采到。本数据卡片还说明3月起返回深度受限，因此深度截断不能解释成代理无法继续对话。

## 原文的两个口径
03 的 flat 指被观察到的有评论线程没有超过顶层；04 v2 的树形分析又限制讨论规模与完整性。两个百分比的分母不同，不能直接相减。还要区分原始 depth 列与根据 parent_id 重建的深度。

## 计算
在单个线程内用带访问状态的遍历重建深度，遇环或断裂就标为未知，不无限递归。大图不把全部文本放入内存。
