# 基尼系数

**一句话**：基尼系数衡量某种非负数量在一组对象之间分配得有多不均。

## 公式
对非负x_i，G=Σ_iΣ_j|x_i−x_j|/(2NΣ_i x_i)。实际计算用排序公式，避免N²矩阵。总和为0时没有通常意义上的G，应说明处理。有限样本最大值与归一化约定也要写清。

## 对象和量都要说明
每个账号的发帖数、收到的评论数、帖子点赞数和账号karma的Gini是不同量。若包含负karma，普通非负Gini公式不适用；不能随便平移后仍与别人原值比较。

## 一个直观对照
100个账号各发10条，数量相同，G接近0。一人发1000条、其余没有，G接近1。若把零活动账号排除，集中程度会改变。

## 本项目怎样用
除了G，报告前1%/前10%占比、分位数与洛伦兹累计份额。按账号平均、按线程平均、按评论加权会得到不同视角。高度集中说明总体平均可能由少数主体支配，接着应做去极端账号与等账号权重的稳健性分析。
