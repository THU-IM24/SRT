# 核心与边缘

**一句话**：核心与边缘描述连接在网络内部如何集中，而不是简单把高产账号叫作核心。

## k-core 的操作定义
在无向图上反复删除度小于 k 的节点，留下的最大子图称为 k-core。节点能进入的最大 k 称 coreness。一个巨大星形图的中心度很高，但它和叶子都只有 coreness=1。这说明高连接与嵌入稠密核心不同。

## 本项目的约定
入门分析先把主网络二值化并无向化，明确这一步丢失方向。再算 coreness 的分布与各层账号数。不要把这种 k-core 分解直接等同于拟合了核心—边缘块模型；后者有自己的统计定义。

## 怎样连接功能
用前一时间窗的核心位置预测后一时间窗的功能指标，避免同一批回复同时定义核心又充当结果。控制前期活动量，比较核心、边缘和桥接位置的回楼及承接率。

## 已有研究与边界
核心—边缘本身已有 Moltbook 专文，见文献检索记录。新增一张核心图不构成新方向。若要分析定向删除节点，只在离线图上做模拟，不修改平台账号。删除试验检验的是图连通性，不能直接证明真实社会系统韧性。
