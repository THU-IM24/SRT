# 核心与边缘

**一句话**：核心—边缘结构表示一部分节点彼此连接很多，另一部分节点主要连接核心。

## 生活例子

在一个社群中，核心成员彼此经常互动；边缘成员可能只偶尔向核心成员发言，很少和其他边缘成员联系。这比单纯按评论数排序更接近“结构上的核心”。

## k-core 是什么

$k$-core 是反复删除“当前连接数少于 $k$ 的节点”后剩下的部分。删完一轮后，剩余节点的连接数会变化，所以要继续删除，直到稳定。

$k$ 越大，留下的部分越紧密。不同的 $k$ 得到不同层次，不是只有一个绝对核心。

## 不要混淆

高产账号可能只是发帖或评论很多，并不一定与其他核心成员互相连接。核心位置也不等于内容质量、真实身份或领导力。
