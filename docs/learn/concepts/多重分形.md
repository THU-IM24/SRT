# 多重分形

**一句话**：多重分形用一组尺度指数描述不同密度区域的缩放差异，比单个维数更细。

## 认识符号即可
常见分析研究不同尺度 s、矩阶 q 下的波动 F_q(s)∝s^h(q)。若 h(q) 随 q 改变，可能存在不同强弱波动的尺度行为。τ(q) 和奇异谱 f(α) 是相关描述。符号 α 在这里不是幂律尾部指数。

## 01 怎样做
作者对最大强连通分量的距离信息做多重分形分析，用来解释局部聚集和全局稀疏可能并存。它是原文的补充结构分析，不是判断社区有无交往功能的必要步骤。

## 复现时要问
网络节点如何排序？矩阵怎样展平？是否受节点重标号影响？尺度区间和有限样本会不会制造谱宽？应比较节点置换、替代数据与不同尺度范围。一个弯曲谱图不能单独证明稳定的生成机制。

## 本项目优先级
列为理解原文的选读概念。不要在 8G 共享服务器上构造全图全对距离矩阵。先完成数据质量、主网络和回复链。只有明确问题需要尺度分析，且有足够计算预算时再做。
