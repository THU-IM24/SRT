# 多重分形

**一句话**：多重分形用多个尺度指标描述网络中不同密度区域的差异，比一个平均维数更细。

## 先不用怕符号

把网络想成一张有密有疏的地图：有的地方连接很密，有的地方很稀。如果所有区域随尺度变化方式相似，一个指数可能够用；如果不同区域变化不同，就可能需要多重分形描述。

常见分析会改变尺度和权重，得到一组指数 $D_q$，而不是只得到一个维数。这里的 $q$ 是“更重视密集区域还是稀疏区域”的调节参数。

## 不要把它当成什么

多重分形不是社区检测，也不是小世界检验。它对尺度范围、网络嵌入方式、样本量和算法实现都敏感。

## 只需记住

这是进阶描述工具。若主问题只是比较连接数量、互惠或对话功能，不必先做多重分形。
