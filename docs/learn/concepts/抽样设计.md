# 抽样设计

抽样设计规定研究材料如何进入样本，以及样本可以代表哪个总体。同样抽100条评论，随机抽评论和先等概率抽线程再各抽一条，得到的权重通常不同。本研究要用有限人工编码估计承接率，必须先确定目标是典型父子对、典型线程还是典型账号。没有这一步，挑到的好对话再多也不能外推总体。

## 先写目标总体，再选抽样单位

承接主分析的候选总体是固定窗口内符合过滤、父节点可解析且正文可读的真实父子对。顶层以帖子为父，楼中楼以父评论为父。缺失对象和排除原因要另报，不能让“可解析总体”悄悄变成“平台全部评论”。

假设两个线程分别有90对、10对候选父子对。等概率抽父子对时，大线程期望占90%；先等概率抽线程、再各抽一对时，两帖各占50%。后者适合等线程视角，但若要估计父子对总体比例，就要恢复各对的入样概率。

若从N个线程抽k个，并在所抽线程内从N_j对抽m_j对，那么两阶段入样概率π_i=(k/N)×(m_j/N_j)，前提是两阶段均为所述等概率无放回抽样。不能仅用第二阶段权重。

## 分层过抽样怎样还原总体

月份、线程规模、层级、是否涉及帖主或模板情况可以作为分层变量。正式分层选少量与问题相关且互不重叠的层，不把每个条件都交叉成极小单元。

层h有N_h对，简单随机抽n_h对时，每对π_i=n_h/N_h，设计权重w_i=N_h/n_h。总体承接率用可判样本的加权承接和／可判样本的权重和；“不可判”仍按[语义承接](语义承接.md)另报。

例如浅层900对抽90对，深层100对抽50对；两层权重分别为10和2。直接平均140对会高估深层的总体占比，使用权重才能还原这套抽样对应的父子对总体。等线程、等账号分析是其他估计目标，另报，不能混称同一个总体率。

## 稳定哈希用于复现，不自动保证代表性

可用固定盐值加ID计算哈希，在各层按哈希排序选取；记录算法、盐值与候选集合。作为正式概率设计时，应说明随机化依据，不能将任意挑选后再排序称为随机抽样。教程的固定哈希小样本首先用于可复现练习。

## 试标、验证与关联性

试标用于改手册；冻结后的正式验证集应与试标分开。调过模型或prompt的样本不能再作为独立测试。按线程或作者分组隔离，并说明使用哪种，能减少相似文本泄漏。

同帖评论相关，真实与错配父消息共用子回复也相关。区间估计应保留相应分组或配对结构；设计权重恢复入样比例，不会自动消除相关性或覆盖偏差。

保存候选总体SQL、层内N_h/n_h、种子或哈希规则、抽样ID和排除流程。ID与正文保留在成员私有输出，公开只放方法与脱敏汇总；具体流程见[教程06](../tutorials/06-抽样与人工编码对话功能.md)。
