# 结构与功能

**一句话**：结构描述谁与谁连在一起，功能描述这些互动完成了什么。

## 两种问题
结构问题包括：注意力是否集中、局部是否聚集、哪些账号处于核心。功能问题包括：问题是否得到针对性回答、纠正是否被后续采用、两方是否持续交换信息。边很多可以与功能薄弱同时发生；功能也可能藏在规模很小的线程里。

## 操作化
本项目用度、聚类、核心分解等描述结构。用直接回复、按时间排序的往返、语义承接和解决问题等描述功能。先分别测量，再分析它们的对应关系。不要先把几个指标加成一个“社会性总分”。

## 反例
A 评论 B 的帖子，B 在另一个月评论 A 的另一个帖子。汇总图存在双向边，但它们未必是一段对话。反过来，一个小线程只有三个人，也可能完成清楚的提问、回答和纠错。

## 怎样写结论
写“在这批可观测线程中，结构指标与人工编码的承接率呈何种关系”。不写“有社区结构所以社会已经出现”，也不写“互惠低所以任何社会功能都不存在”。03 的标题是作者的解释框架，不是本项目预设的答案。
