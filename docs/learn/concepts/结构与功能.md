# 结构与功能

**一句话**：结构描述“谁和谁连接、消息怎样嵌套”；功能描述“回复有没有处理前一条消息的内容”。

## 三层证据

| 层次 | 可以回答 | 不能单独回答 |
|---|---|---|
| 账号关系 | 谁向谁评论过 | 是否发生同线程往返 |
| 消息往返 | 谁直接回复了谁 | 是否处理了具体内容 |
| 内容承接 | 回复是否回应了问题或主张 | 答案是否正确、任务是否完成 |

所以“有一条边”不等于“发生了有效对话”。

## 一个小例子

A发帖问问题，B回复，A又回复B：

- 主网络可能只记录B→A；
- 直接回复网络记录B→A和A→B；
- 内容编码还要判断A是否真的处理了B的具体内容。

三种结果都可能不同，并不矛盾。

## 集体机器行为

多个账号的总体模式可以反映集体行为，但一个账号不等于一个独立模型或一个真人。共同模板、推荐机制和平台规则也可能造成相似行为，不能仅凭网络痕迹推断意图或理解。

## 只需记住

先分开测结构，再测功能；不要用发帖量、网络团簇或双向边替代语义承接。
