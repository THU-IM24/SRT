# 路径长度

**一句话**：路径长度是沿网络连接从一个节点走到另一个节点需要的步数；全局效率用距离的倒数，把不可达点对也纳入比较。

## 定义
二值图的最短路径 d(i,j) 是最少边数；有向图必须顺着箭头。平均最短路径 L 是指定节点对集合上的距离均值。路径不存在时不能直接用 0 填。

## 分母决定含义
可以只在 LSCC 内求所有节点对，也可以在全图只求可达对，但后者会忽略根本到不了的节点。报告选择、分量覆盖比例和不可达比例。01 同时讨论分量和全图尺度，正是提醒局部结果不能直接替代全局。

## 全局效率
全局效率把距离取倒数，使不可达节点对能以 0 纳入网络的可达性测量。常用公式是：

E=Σ_(i≠j) 1/d(i,j) / [N(N−1)]，约定不可达时 1/∞=0。N 是指定节点全集的节点数，有向图使用有序节点对。

平均路径若只对可达对求均值，一个高度碎片化网络也可能显得路径很短。全局效率保留不可达对的分母惩罚；若软件只对可达对归一化，它算的是另一个量，不能仍称同一个公式。

01 的文字同时出现“全网效率”和“排除不可达对”的表述。学习时要理解标准公式；复现作者数值时要核查实现和归一化。不能为贴近结论而悄悄更换分母。

## 玩具例子
A→B→C 中 A 到 C 距离为 2，C 到 A 不可达。把图无向化以后 C 到 A 也变成 2，问题已经改变。

保留方向时，三个可达有序点对的距离是 1、2、1，所以可达对平均路径 L=4/3；全局效率 E=(1+1/2+1)/6=5/12。再加入一个孤立节点，可达对平均路径不变，但全局效率降为 (1+1/2+1)/12=5/24。这正是两种分母回答的问题不同。

## 计算与比较
不要在千万评论形成的大图上先生成 N×N 距离矩阵。先用分量和节点数判断规模。必要时抽样源节点，用 BFS 求距离，保存源节点抽样规则，并报告种子、抽样数、方向及误差。

同一节点全集下比较主网络与随机图，另报最大分量占比。路径和效率描述结构上的潜在触达，不证明内容真的沿路径传播到了接收者，更不证明信息被理解。
