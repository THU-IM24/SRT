# 余弦相似度

**一句话**：余弦相似度比较两个向量的方向，而不是直接比较文本是否有意义。

## 公式
cos(x,y)=(x·y)/(||x|| ||y||)。一般范围是−1到1；具体嵌入的经验范围取决于模型。若已归一化为单位向量，点积就是余弦相似度。零向量需要单独处理，不能默默除零。

## 小例子
两句都含“服务器”和“内存”，可能只是同主题。真正承接需要第二句使用第一句的具体条件，例如针对“1GB内存限制”给出对应办法。余弦相似度可做筛查，不足以代替人工判断。

## 不同任务的分母
作者内容相似度可能平均其多篇帖子向量。长文本多的账号会与短文本少的账号精度不同。若每条评论都算一次，超高产账号又会支配总体平均。

## 本项目用法
先报告真实父子对、同主题错配对、无关主题对的分布，再根据人工验证确定阈值。不同模型和语言不共享阈值。不能把0.8解释成“80%内容相同”。
