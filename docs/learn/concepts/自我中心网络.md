# 自我中心网络

**一句话**：自我中心网络从一个焦点账号出发，只看它周围一跳、两跳或三跳内的关系。

## 例子

选中账号A：

- 一跳：A直接连接的账号；
- 两跳：A的邻居所连接的账号；
- 三跳：再向外扩一层。

有向图还要决定看谁指向A、A指向谁，还是忽略方向。

## 它能回答什么

它适合观察某个账号周围是一个紧密小圈子、一个星形网络，还是连接了多个群体。但焦点账号的选择和保留哪些边会强烈影响图形。

## 不要外推

一个高入度账号的三跳邻域像团簇，只能说明这个局部。它不能证明全图是小世界，也不能证明邻居之间发生了有意义的对话。

相关概念：[小世界](小世界.md)、[中心性](中心性.md)。
