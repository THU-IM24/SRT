# 自我中心网络

**一句话**：自我中心网络以一个焦点账号为起点，保留指定跳数内的邻居与关系。

## 邻域怎么取
一跳网络含直接邻居，二跳加入邻居的邻居。有向图还要决定取入邻居、出邻居还是忽略方向。应说明是否包含邻居之间的所有原始边；只保留连向焦点的边天然像星形。

## 论文怎样用
01检查高入度账号的三跳局部结构。02提取经验机器人与人类的二跳自我中心图作为视觉参照。焦点账号的选择、跳数与保边规则不同，图形不能直接比较。

## 本项目用法
可以选高入度、低入度与高模板率账号各若干，观察它们的关系对象，再回到具体线程验证。但少数挑选案例不能代表全平台。先定焦点抽样规则，报告局部节点数与全图覆盖。

局部聚类或短路径不能外推为全图小世界。焦点是高产账号时，其邻域规模也可能主要由活动量决定。
