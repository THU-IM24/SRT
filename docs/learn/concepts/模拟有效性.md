# 模拟有效性

**一句话**：模拟有效性问的是“模型是否可信地表示了目标现象”，不是“图画得像不像”。

## 三层检查

1. **输入有效**：模型使用的规则、数据和角色设定是否对应真实问题；
2. **过程有效**：行动者如何互动，是否与观察到的机制相符；
3. **结果有效**：模型能否复现目标分布、时间模式或网络结构。

只复现一个平均数远远不够；不同错误机制也可能得到同一个平均数。

## 一个反例

模型生成了与真实网络相似的度分布，但所有边都是随机生成的。它可以复现一个结果，却没有复现互动过程，因此不能据此说模型解释了真实关系。

## 只需记住

比较前先固定指标、窗口、基线和重复次数；结果只推广到验证过的场景。合成数据上的通过，不等于现实效果或真实动机已经被证明。
