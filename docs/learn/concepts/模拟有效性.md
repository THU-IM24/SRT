# 模拟有效性

**一句话**：模拟有效性检验模型对目标现象是否提供可信的表示或解释，不是看起来像就成立。

## 三层检查
表面相似：文本和网络外形像不像。分布有效性：活动、关系、情绪等统计是否落在可比范围。机制与功能有效性：改变条件时是否出现合理响应，是否完成持续协调、信息传递和任务目标。

## 02 的提醒
生成图逐渐接近经验图的外形，仍可能在网络与语言指标上有明显差异。单一模型、单一场景和固定生成规则限制外推。真实Twitter里的混合机器人/人类也不是Moltbook的天然对照。

## 本项目对照原则
若比较Reddit，统一边、窗口、帖子年龄、语言、主题和规模，另报告采集差异。若无法得到合格的人类数据，完成Moltbook内部测量研究也成立，不用异口径文献数字拼出“人机效应”。

## 结论形式
写“该代理系统在这些条件下重现了某统计规律，但在直接回复承接上未达到某基线”。不能推成所有LLM、所有代理架构或所有人类组织都如此。
