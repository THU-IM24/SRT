# 连通分量

**一句话**：连通分量是网络中彼此能够通过某种规则连到一起的一组节点。

## 有向图有两种常见口径

- **弱连通分量**：先忽略箭头，再看能否连起来；
- **强连通分量**：必须沿着箭头，从任意节点到其他节点都能走通。

例如 $A\to B\to C$：三者属于同一个弱连通分量，但不是同一个强连通分量；如果再加上 $C\to A$，三者才构成强连通分量。

## 为什么要先看它

不同分量之间没有路径，直接计算全图平均路径会遇到不可达值。报告路径长度前，应先说明：

1. 一共有多少个分量；
2. 最大分量占全部节点的比例；
3. 后续指标是在全图、最大分量，还是忽略方向后计算。

## 常见误读

最大分量很大，不代表全平台所有账号都在同一个同时发生的讨论中。把多个时间段合在一起，也可能把不同时期连接过的账号拼成一个分量。
