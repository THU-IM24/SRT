# 全局效率

**一句话**：全局效率把距离取倒数，使不可达节点对能以 0 纳入网络的可达性测量。

## 常用公式
E=Σ_(i≠j) 1/d(i,j) / [N(N−1)]，约定不可达时 1/∞=0。有向图使用有序节点对。这种定义保留不可达对的惩罚。

## 与平均路径的差别
若只对可达对求平均距离，一个高度碎片化网络也可能显得路径很短。全局效率把未连接部分算入分母。若软件只对可达对归一化，它算的是另一个量，不能仍称同一个公式。

## 与原文的关系
01 的文字同时出现“全网效率”和“排除不可达对”的表述。学习时要理解标准公式；复现作者数值时要核查实现和归一化。不能为贴近结论而悄悄更换分母。

## 本项目怎样用
同一节点全集下比较主网络与随机图，另报最大分量占比。如果对大量源节点抽样估计效率，保存源节点抽样规则。效率描述结构上的潜在触达，不证明内容真的传到了接收者，更不证明信息被理解。
