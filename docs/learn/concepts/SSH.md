# SSH

**一句话**：SSH 是一种安全地“远程登录另一台电脑”的方式，登录后你输入的命令都在那台电脑上运行。

**怎么用**：在 PowerShell 里运行 `ssh 用户名@地址`，或者在 `~/.ssh/config` 里给服务器起个别名（例如 `srt`），以后只要 `ssh srt`。VS Code 的 Remote - SSH 插件也是用它连服务器的。SSH 一般不用密码，而是用一对钥匙认证。

**在本项目里**：大家用 SSH 连到阿里云服务器 `101.201.117.95`；服务器也用 SSH 和 GitHub 通信（`git@github.com:...`）。

**相关概念**：[公钥与私钥](公钥与私钥.md)
