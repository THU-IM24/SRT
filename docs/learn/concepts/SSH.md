# SSH

**一句话**：SSH 是一种安全地“远程登录另一台电脑”的方式，登录后你输入的命令都在那台电脑上运行。

## 怎么用
在 PowerShell 里运行 `ssh 用户名@地址`，或者在 `~/.ssh/config` 里给服务器起个别名，以后用 `ssh 别名`。VS Code 的 Remote - SSH 插件也是用它连服务器的。本项目用公钥认证登录。

## 公钥与私钥
公钥与私钥是一对配套的密钥文件。公钥可以交给服务器或 GitHub；私钥只由自己保管，不能发给任何人。连接时，客户端用私钥证明身份，对方用公钥验证。

运行 `ssh-keygen -t ed25519` 会生成：

- `id_ed25519.pub`：公钥，可以公开。
- `id_ed25519`：私钥，绝不能分享。设置了私钥口令时，使用它仍可能需要输入口令。

## 在本项目里
大家用 SSH 连到阿里云服务器 `101.201.117.95`；服务器也用 SSH 和 GitHub 通信（`git@github.com:...`）。两种连接的公钥配置位置不同：

- 电脑登录服务器：电脑保管私钥，把公钥交给服务器管理员配置。
- 服务器访问 GitHub：服务器保管用于此次连接的私钥，把配套公钥加到 GitHub。

具体步骤见[服务器上手教程](../tutorials/服务器上手教程.md)。
