# 社区语义一致性

**一句话**：社区语义一致性研究社区身份、内部内容和跨社区联系是否在语义上相互对应；主题熵只描述其中的主题分散程度。

## 分开三层
内部一致性：同社区文本彼此有多接近。身份一致性：文本与社区名称或描述是否相关。社区区分度：不同社区的内容分布能否区别。内部可以很多样，同时仍有稳定身份；低熵不是所有意义上的高一致性。

## 主题熵
主题熵衡量一组文本的主题分布有多分散，不直接测量内容是否连贯。

H=−Σ p_k log(p_k)，p_k 为第k主题的比例，0log0约定为0。必须报告对数底。使用自然对数时上限是 ln(K)，底2时上限是 log₂(K)。标准化熵为 H/log(K)，但只有同一标签体系下才可比；K=1时该标准化式没有定义。

某社区90%是技术、10%是艺术，熵低于各占50%。这说明分布更集中，不说明它更能完成技术问答。高熵也可能表示一个开放综合社区有广泛话题，而且内容仍符合社区名称或描述。

03 用主题熵描述社区混合程度，并筛选了有足够帖子数的社区。只有一篇帖子的社区天然熵为0，不能据此称其主题高度组织化。使用时统一标签和语言，限定最小样本，报告小社区的不确定性，再比较社区间分布与社区名—内容一致性。主题多样性、群体间差异和关系同质性是不同量，不应互相替代。

主题熵的原文章节：03 §6.2；01 §4.3。

## 设计对照
比较社区内部文本与相同规模的随机分组，匹配语言、时间和作者。共享作者跨社区复制同一段模板，会压低区分度。删除共享作者后的变化是稳健性分析，不是可以随意挑选的主结果。

## 本项目怎样用
当研究结构与功能关联时，社区语义只作为背景或分层变量。可在同主题、同月、相近规模线程中比较真正的回复承接，避免把主题相同当作对话。

## 新颖性边界
Moltbook与Reddit的社区一致性和多样性已经有直接研究，Social Simulacra 也研究共同作者造成的表面同质化。新加一个嵌入模型不构成新的理论问题。
