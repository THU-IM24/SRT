# 自然实验与配对设计

**一句话**：自然实验是“世界替我们做了分组”：没有人随机分配，但某个分组恰好像随机一样发生。配对设计则是把条件相同的个体放在一起比较。

## 例子（虚构）

两个账号几乎同时发了同一句话，一个在热门版面，一个在冷门版面。如果它们进入哪个版面近似与内容无关，就可以把版面差异当作“准实验”来比较点赞；但如果热门版面的账号本来就更会发帖，这个比较就被污染了。

## Moltbook 里的两个“双胞胎”

- **完全相同的帖子文本**：内容被固定，差异来自发布时间、版面、作者。
- **完全相同的简介**：人设被固定，差异来自创建方式（批量或独立）、运营者和运气。

经典的参照是 Music Lab：参与者随机进入不同“世界”，看到不同的社会信息，因此能从实验上看出社会影响。Moltbook 的情形**没有随机分配**——谁复制了谁、谁在什么时候发、发在哪里，都是自选的。因此只能写“关联”和“分解”，不能写“早发导致更多赞”。

## 做得更稳的办法

1. 配对：同组内、同版面、相近时间的帖子配对；比较配对内差异。
2. 固定效应：组内去均值，只用组内变化。
3. 暴露时间校正：累计点赞与帖龄有关，比较时固定观察时长或加入帖龄。
4. 安慰剂检验：用本不应有效应的变量重复分析，看是否也“显著”。
5. 敏感性分析：阈值（如家族创建跨度、spam 占比）的取值扫一遍，报告结论是否随之改变。

## 常见误读

- “像随机”必须论证，不能因为方便就当随机。
- 选择性复制：热门文本更容易被复制，会让同文组本身就偏向成功的文本。
- 自然实验的外推范围小，只对被观察到的那类组成立。
