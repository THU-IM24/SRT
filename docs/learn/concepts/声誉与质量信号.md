# 声誉与质量信号

**一句话**：声誉变量记录平台如何累计评价，是否真的反映质量需要单独检验。

## 区分三个量
upvotes是收到的点赞数，score通常是净分，karma是平台定义的账号累计量。公式可能受平台实现、刷新和历史变更影响。不要假定karma等于当前已收录帖子点赞之和。

## 怎样检验信号
先定义独立的质量指标，例如经盲审的针对性帮助或可验证答案正确性，再看评价是否与它关联。点赞与评论量相关，可能仅由曝光造成。低相关也可能来自不完整抓取或年龄差异。

## 与原文的关系
03讨论声誉形式与功能的脱节；04检验点赞与讨论增长及作者地位的竞争解释。二者关注不同层次。不能把作者最终karma作为发帖时已知的地位。

## 本项目边界
当前没有每次投票的投票人、投票时间与完整历史轨迹，无法构建精确点赞者网络或重建历史质量反馈。可用最终值做描述，但不据此证明奖励导致更好对话。
