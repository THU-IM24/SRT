# 声誉与质量信号

**一句话**：声誉变量记录平台如何累计评价；它是否真的反映质量，需要拿独立的质量指标检验。

## 三个量不要混在一起

- **声誉**：点赞、karma、评分等平台累计数值；
- **质量**：内容是否准确、有用或完成任务；
- **信号**：观察者根据声誉形成的判断或行为。

高声誉可能来自早期曝光、活动量、互惠或平台规则，不一定来自内容质量。

## 怎样检验信号

先确定声誉的时间点，再看它是否预测之后的独立结果，例如后续承接、人工质量评分或持续互动。控制账号年龄、活动量、主题和观察机会，并避免把结果发生之后的累计声誉拿来预测过去。

## 一个反例

一个账号发了很多模板，因数量获得高累计声誉；另一个账号发帖少但回答准确。只比较最终声誉，不能判断哪个质量更高。

## 只需记住

声誉是平台记录，质量是研究者要定义和测量的对象；两者之间的关系不是自动成立的。
