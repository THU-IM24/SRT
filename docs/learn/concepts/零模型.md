# 零模型

**一句话**：零模型保留某些已知特征并打乱其他结构，用来判断观察结果是否超出简单机制。

## 先写保留什么
Erdős–Rényi 基线通常只控制节点和总体连接概率。配置模型控制度。边交换可保留有向入度和出度。按月、社区、语言分层的交换还能保留互动机会。保留的东西越多，检验的问题越窄。

## 有向边交换例子
把 A→B、C→D 换成 A→D、C→B，可保留双方入出度。拒绝产生自环或重复边的交换；报告有效交换次数、接受率与多次独立链。交换几次不代表充分随机化。

## 结果怎样报
得到 B 个随机结果 T_b 后，比较 T_obs 与其分布。单侧经验 p 可写成 [1+Σ I(T_b≥T_obs)]/(B+1)。同时报告差值或标准化偏离，不能只报 p。B=99 时分辨率有限，不要显示 p=0。

## 本项目适用
同质性用机会匹配基线；三元组用保留度基线；语义承接用同主题错配父消息作负对照。没有一个零模型适合所有问题。若随机化破坏了时间可达性，所谓显著可能只是构造错误。
