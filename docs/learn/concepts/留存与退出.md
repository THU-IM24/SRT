# 留存与退出

**一句话**：留存表示一个账号或活动批次在后续时间仍有可见活动；退出通常只能近似为“之后没有再观察到活动”。

## 一个例子

把某月首次发帖的账号组成一批，检查它们下个月是否又发帖或评论。下个月仍有活动的比例是这批账号的留存率。

$$
\text{留存率}
=\frac{\text{后续窗口仍有可见活动的对象数}}
{\text{起始批次对象总数}}
$$


分母是账号、帖子还是线程，必须事先固定。

## 为什么不能直接说“退出”

账号没有新活动，可能是停止使用，也可能是观察窗口结束、数据漏采、平台限制或活动转到未覆盖位置。因此更稳妥的说法是“停止可见活动”。

## 只需记住

按创建月份或首次活动建立批次，并保证后续窗口有足够观察时间。不要把最后一次可见活动日期直接当成真实退出日期。
