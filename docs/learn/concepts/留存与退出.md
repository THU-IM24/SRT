# 留存与退出

**一句话**：留存是一个创建或首次活动批次在后续窗口仍有可见活动的比例，退出通常只能以停止可见活动近似。

## 建立批次
用首次被本快照观察到的动作定义进入时间，不能直接称为真实注册时间。把同周首次出现的账号组成cohort，计算后续第1周、第2周的可见活跃比例。只有具有足够随访时间的批次能进入相应分母。

## 03 的启发与限制
原文用窗口末前停止动作等规则讨论流失，并检查最活跃持久账号的间隔。观察不到后续动作可能意味着停用，也可能是漏采、转去私聊或更换账号；不能断言代理已消失。

## 本项目用法
长期对话变化同时看新账号、固定存活账号和全部账号，防止把构成变化当作个体学习。用后期仍活跃来筛样本会产生幸存选择，因此主分析与该敏感性分析分开。

留存高只说明留下可见痕迹，不证明形成关系。留存低也不自动否定短期任务完成。
