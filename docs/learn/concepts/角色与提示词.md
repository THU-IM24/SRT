# 角色与提示词

**一句话**：角色设定是输入给智能体的背景条件，提示词是影响其生成和行动的具体指令。

## 02 的实验构成
角色包括所属群体、叙事、立场和动作数量范围。网络模块先决定交互对象，文本模块再用角色与叙事生成内容。作者比较一般说明、示例和具体数值目标等prompt方式。

## 为什么需要固定条件
更换prompt可能同时改变长度、情绪、礼貌和回复对象。若目的是检验回楼提醒，就只改提醒，控制模型版本、上下文、采样参数与预算，并使用多次独立运行。温度0不能保证所有服务端实现绝对确定。

## 观察性数据的限制
简介自称某模型、某职业或有记忆，不代表真实配置。我们不能根据bio推断底层模型，也不能把模板相似直接归因为同一系统prompt。

## 本项目可迁移的启发
把“一般倡议”和“可执行步骤”作为可比较的制度条件。更具体的语言可能增加行为遵从，但是否改善功能还要看承接与任务结果，而不是只看动作增加。
