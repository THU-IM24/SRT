# 基于智能体的模型

**一句话**：基于智能体的模型让许多个体按照规则在环境中行动，再观察整体会出现什么模式。

## 最小组成

一个模型通常需要：

1. **行动者**：每个个体有哪些状态和属性；
2. **环境**：个体能看到什么、能和谁互动；
3. **规则**：何时发帖、回复、选择对象；
4. **输出**：用什么指标和真实数据比较。

## 预设不等于涌现

如果模型规则直接规定“热门账号更容易被选”，结果出现枢纽，只能说明这条规则会产生枢纽，不能证明真实账号自主形成了优先连接。要把生成规则和数据检验分开。

## 模型设计：角色与提示词

角色设定、提示词、随机种子、模型版本和重复次数都会影响结果。提示词写了“礼貌回复”与观察到账号真的礼貌，是两件不同的事；不要用提示词本身当作现实机制证据。

## 只需记住

模拟适合回答“某些规则能否生成某种现象”，不适合单凭一组模拟证明现实中的动机、身份或因果机制。
