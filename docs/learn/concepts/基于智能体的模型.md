# 基于智能体的模型

**一句话**：基于智能体的模型用多个有规则的行动者在环境中运行，观察总体模式。

## 最小组成
规定行动者的状态、可见信息、动作、更新顺序和环境反馈。传统ABM常用明确规则；LLM-ABM用语言模型产生部分决策或文本。02 采用规则生成连接、语言模型生成文本的混合方式。

## 必须区分生成来源
若网络连接由优先连接算法指定，LLM只是写文字，那么枢纽和群组有多少可能来自算法。不能把程序预设的关系称作模型自发社会性。研究时可对连接模块与文本模块分别消融。

## 一个本项目可做的设计
离线设置无提醒、回楼提醒、记忆摘要、明确互惠任务等条件，固定代理数、轮数、token预算和任务。结果同时记录回应概率、内容承接、正确率与成本，不只看回复次数。

## 优先级与成本
先完成现有数据的观察性基线。实验需要模型访问与可能费用，本次只写方案，不调用付费接口。模拟不在真实社区发帖，不把观察到的外部文本当作可执行指令。
