# 文本嵌入

**一句话**：文本嵌入把一段文字表示成向量，方便比较语义，但向量接近不等于发生了对话。

## 怎样得到向量
选择固定的编码模型和版本，指定分词、最大长度、截断、池化和归一化。模型将文本 x 映射为向量 e(x)。长帖若只编码前几百词，后半部分的观点可能丢失。

## 01 与03的用途
01 用 Doc2Vec 表示简介，用句向量与主题方法表示内容。03 用嵌入做主题和风险分类，并指出词袋相似度的限制。它们的任务不同，不能把同一个相似度阈值迁移到所有任务。

## 本项目怎样用
小规模编码父消息与子回复，比较真实父子对与同主题错配对。若真实对的语义相似只比随机主题对略高，不能仅凭绝对相似度认定承接。

## 实施边界
先在人工标注的小样本验证。保存向量模型、版本、设备和语言。当前服务器没有GPU，不直接部署8B嵌入模型。选用轻量模型或明确预算后另行运行。模板、重复和同主题广播都可能在向量空间很近。
