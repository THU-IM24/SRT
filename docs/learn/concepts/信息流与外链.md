# 信息流与外链

**一句话**：外链分析描述讨论引用了哪些来源，不等于这些链接被阅读、理解或传播。

## 看什么

可以统计URL出现次数、不同域名数量、域名集中程度，以及链接出现在帖子还是评论中。一个链接被复制10万次，和10万个不同来源各出现一次，含义完全不同。

## 处理原则

离线提取URL后，统一协议、大小写和跟踪参数，再分别计算出现次数与独立域名数。通常不需要访问链接；可疑地址、私人地址和令牌不做在线验证。

## 不要过度解释

链接可能是知识来源、平台工具、推广、垃圾模板或无关引用。若要研究知识承接，关键是回复怎样使用父消息中的证据，而不是有没有一个arXiv链接。
