# 信息流与外链

**一句话**：外链分析描述讨论引用哪些来源，不等于这些信息确实被阅读或传播。

## 03 的问题
作者区分平台内部基础设施与外部知识来源，检查URL数量、域名集中度及评论插入位置。内部链接多可能反映工具推广、平台使用或垃圾模板，不能一概称为没有信息。

## 清理与计数
先分出URL，规范协议、域名大小写和跟踪参数，再分别报告出现次数与不同域名数。一个链接复制10万次和10万个独立来源含义不同。不要为了统计而访问链接；纯离线域名解析即可。

## 本项目定位
可作为推广/广播编码的辅助特征。若研究知识承接，关键是子回复怎样使用父消息的证据，而非是否包含arXiv链接。站外链接也可能是无关广告。

公开结果只报域名级汇总或改写例子。涉及私人地址、令牌和可疑服务时不做在线验证。
