# 时间互惠

**一句话**：时间互惠要求反向回应在第一次互动之后、指定时间内发生。

## 比静态双向边多了什么
静态图只看 A→B 与 B→A 是否曾出现。时间互惠还要求 t_BA>t_AB，并规定 24 小时、7 天等窗口。同线程往返还要求沿正确父子链发生；跨线程再次见面是另一种结果。

## 严格的三步例子
B 顶层评论 A 的帖子，A 直接回复 B，随后 B 直接回复 A。这是一个有序的 B→A→B 参与序列。顺序相邻但不沿同一父子链的三条评论，不一定构成这段往返。

## 分母与删失
分母是有足够后续观察时间的首次互动机会，不是所有最终边。创建于快照结束前 1 小时的评论不能进入“7 天无回应”的分母。把同对账号的许多事件当独立样本，会低估不确定性。

## 本项目如何用
同时给静态双向边、24 小时直接回覆和7天跨帖再互动，分开命名。再加入语义编码，检验形式上的往返是否针对父消息内容。相关研究已经研究对话持续和二人关系，不能把“首次分析时间互惠”写成创新。
