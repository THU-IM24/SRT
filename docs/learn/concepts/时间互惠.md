# 时间互惠

时间互惠关注互动发生后，是否在规定时间内出现反向回应。静态互惠只要求两个方向的账号边存在，不保证先后、同帖或实际父子关系。本研究把“同线程三步往返”与“7天跨帖再互动”分开定义。这样才能判断双向连边是否对应可追踪的持续互动，而非两个互不相关的事件。

## 作者顺序与账号边分别写

A为帖主。B在09:00发c1，A在10:00直接回复c1形成c2，B在11:00直接回复c2形成c3。三条评论的作者序列为B、A、B；这里的三个字母是三次发言，不是两条账号边。

若c1为顶层评论，直接回复网络依次得到B→A、A→B、B→A。主网络却会删掉A在自己帖内的c2。因此静态图不能代替逐消息核对。

若c3改到次日10:00，父子链仍存在，却已超过从c1起算的24小时。若B在11:00回的是同帖C的评论，也不构成这条B、A、B链。

## 主分析的两个24小时指标

以一条合格非帖主评论c1为机会，t0为其创建时间：

| 指标 | 窗内条件 | 分母 |
|---|---|---|
| 严格帖主回应率 | c2直接回复c1，作者为帖主A，且t0<t2≤t0+24小时 | 合格起始评论数 |
| 三步往返率 | 再有c3直接回复c2，作者为原评论者B，且t2<t3≤t0+24小时 | 同一批合格起始评论数 |

两个指标每条起始评论至多成功一次。不是把前一次获回应者当作三步往返率的分母，也不是每一步重新计24小时。所有符合规则的非帖主评论都可成为机会，含完成上一段往返的评论；详见[帖主回楼的手算例子](帖主回楼.md#一帖为什么会有三个机会虚构)。

两项都要求完整24小时随访及覆盖合格。等时间戳不能强行排出顺序；同线程但没有直接父子关系也不算这条链。

## 选读：7天跨帖再互动

以一对账号首次可见的合格非自回复事件为起点，在另一帖子中查找该对账号7天内的直接回复。同向再次互动与反向回应分开报告；任一方向再出现只能称“再互动”，不能统称互惠。

“首次可见”不等于两账号历史上的第一次。正式分析前冻结如何构造无序账号对、是否每对仅保留一个起点、同刻事件如何处理，以及完整7天资格。未冻结前只作为扩展设计，不给总体率。

## 怎样解释和报告

同一线程内多个机会并不独立；误差估计按线程、作者或账号对的依赖结构设计，不能把每条评论都当作独立实验。每项报告事件规则、时区、随访分母与覆盖排除数。

有序往返仍可能只是模板互答，应另看[语义承接](语义承接.md)。24小时／7天均是本项目窗口，不能据此断言长期关系、内部记忆或因果机制。
