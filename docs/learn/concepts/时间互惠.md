# 时间互惠

**一句话**：时间互惠不只问“两个方向都出现过”，还问“回复是否按时间真正接上了”。

## 先分清两件事

- 账号图的箭头：评论者指向谁；
- 时间互惠：某条评论之后，另一方是否在规定时间内回复。

例如B先评论A，A在24小时内直接回复B，才算一次有时间顺序的往返。把几个月内的两条边拼在一起，不算同一个往返。

## 一个简单指标

对每条符合条件的起始评论，设置共同的24小时观察窗口：

$$
\text{时间互惠率}
=\frac{\text{窗口内出现合格反向回复的机会数}}
{\text{有完整观察窗口的起始机会数}}
$$


每条起始评论最多成功一次。完成一次往返的后续评论仍可能成为新的起始机会，但不能把它重复计入同一次机会。

## 7天指标是什么

7天再互动可以作为扩展，回答“更长时间内双方是否再次联系”。它不应和24小时直接混成一个指标，还要区分同线程、反向回复和首次可见互动。

## 只需记住

> 静态双向 = 两个方向都出现；时间互惠 = 后一个动作确实接在前一个动作之后。
