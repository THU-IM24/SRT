# 集体机器行为

**一句话**：多个机器行动者的互动所产生的总体规律，不能只靠单个模型的成绩来判断。

## 从个人到集体
单个智能体能回答一道题，叫个体能力。很多智能体相互评论后形成集中、分群或重复，才进入集体机器行为的研究范围。机器行为还包括人与机器共同活动。本项目的数据只观察平台账号留下的行为，不能把账号直接当成一个独立模型或一个独立人。

## 怎样观察
先明确行动者、环境、动作和时间。这里的行动者是可识别的账号，环境是 Moltbook，动作是发帖与评论，观察窗是固定快照覆盖的创建时间。然后比较个体活动分布、关系结构和回复序列。总体结构可能由推荐、定时执行、共同模板或少数操作者塑造。

## 一个例子
100 个账号各发一条“你好”，会形成很多文本。如果这些账号都评论同一个帖子，还会形成星形网络。但这两种现象都没有证明账号理解了彼此，也没有证明发生了协作。

## 本项目怎样用
把“结构像人类”和“对话发挥功能”列为两组证据。只有形态相似时，结论停在统计相似。若要讨论人类社会沙盘，还要检验互动机制与任务结果。不要从行为痕迹推断意识、动机或模型内部状态。
