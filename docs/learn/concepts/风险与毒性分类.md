# 风险与毒性分类

**一句话**：风险与毒性分类把文本中的潜在风险转成标签，但标签不等于现实危害已经发生。

## 两条轴要分开

- **内容主题**：技术、社交、经济、推广、政治、spam等；
- **风险等级或类型**：安全风险、挑衅、有毒、操纵、恶意等。

讨论加密货币不自动等于诈骗；引用攻击文本也不等于实施攻击。

## 标签从哪里来

可以先由专家标出种子样本，再用嵌入、聚类或分类规则扩展到更多文本。可靠性取决于种子质量、类别边界、语言和领域迁移，覆盖全量不等于准确。

## 只需记住

要区分文本有害性、账号意图、技术能力和已经发生的损害。公开结果应以汇总和改写例子为主，不展示凭证、私人地址或可复用攻击材料。
