# 风险与毒性分类

**一句话**：风险与毒性分类把文本中的潜在危害转成标签，标签不等于现实危害已经发生。

## 03 的两条轴
03 将内容主题与风险等级分开。主题包括身份、技术、社交、经济、观点、推广、政治、spam和其他；风险含安全、挑衅、有毒、操纵与恶意。讨论加密货币不自动等于诈骗，引用攻击文本也不等于实施攻击。

## 方法链
原文由专家种子标注出发，用嵌入、每类多个K-means中心和最近中心规则扩展。这个流程的可靠性取决于种子质量、类别边界、领域迁移和独立验证，不能只因覆盖全量就认为标签准确。

## 本项目怎样涉及
这不是当前主研究结果。用于理解原文，并作为内容编码中识别推广、spam和高风险材料的辅助背景。先在小样本上校验，不在8G服务器直接运行原文的大模型方案。

## 报告与处理
公开只报汇总、定义与经改写例子。区别文本有害性、账号意图、技术能力和已发生的损害。不能从出现一句恶意话语推断整个社区形成了恶意协作。
