# 时间衰减

**一句话**：时间衰减描述内容随着年龄增加，继续获得互动的速度如何变化。

## 两个不同量
新增评论率 λ(t) 是单位时间新增评论数。04 定义的相对增长量 γ(t)=平均[N(t)/N(t−Δt)−1]，只纳入前期累计评论大于0的帖子。γ不是λ，也不是未获回复概率或生存危险率。

## 注意分母
N(t−Δt)=0的帖子无法计算比值。越到后期，进入平均的帖子集合可能变化。必须固定观察时长、说明进入规则，比较相同创建批次。不能把相对增长指数直接当成绝对新增评论率指数。

## 活动持续时间
从帖创建到最后一条被观测评论的时间，只是观察到的持续时间。快照末尾仍可能有后续评论。04 使用固定30天窗口与月度批次，这种结果不等于永久生命周期。

## 本项目怎样用
先估计24小时、7天内直接回复比例，再在足够观察窗口中画分时段数量表。若对比“快速响应”，同时报告没被回复的比例。只看已回复样本的中位等待时间会隐藏沉默的大多数。
