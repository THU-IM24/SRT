# 优先连接

**一句话**：优先连接是假设已有连接较多的节点更容易获得新连接。

## 时间顺序是核心
先在 t0 统计旧入度 k，再统计 t0 到 t1 新增边指向这些节点的次数 m(k)，除以旧度为 k 的节点数 n(k)，得到 A(k)=m(k)/n(k)。这是一种两时期估计，不是最终度数与最终点赞数的相关。

## 比例与机制
若 A(k) 随 k 增长，与优先连接相容。若 A(k)∝k^β，β≈1 是线性优先连接的候选。曝光、账号年龄、语言、发帖量、推荐规则也可能造成相似趋势，观察相关不能独自证明机制。

## 与 02 的区别
02 把优先连接写进模拟生成规则。因此生成网络出现枢纽，不能反过来当成模型自主产生关系偏好的证据。要区分“生成器设定”和“数据中检验”。

## 本项目怎样用
只用此前可观测的度定义分组，以后续第一次接触形成的新二值边为结果；重复评论另分析。初期不把它当主线，因为需要可靠曝光集合。不能仅凭幂律就说优先连接已得到证明。
