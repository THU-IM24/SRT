# 优先连接

**一句话**：优先连接是“已经连接很多的节点，更容易获得新连接”的假设。

## 用例子理解

一个新账号要评论别人时，如果大家更容易看到或选择已经很热门的账号，那么热门账号会继续获得更多连接，形成“强者更强”。

## 为什么必须按时间看

先在时点 $t_0$ 统计每个节点已有的入度 $k$，再看之后新增连接次数 $m(k)$。若度数为 $k$ 的节点共有 $n(k)$ 个，可用：

$$
A(k)=\frac{m(k)}{n(k)}
$$


若 $A(k)$ 随 $k$ 增长，与优先连接相容；若 $A(k)\propto k^\beta$，$\beta\approx1$ 是线性优先连接的候选。

## 不能直接下结论

曝光机会、账号年龄、语言、发帖量和推荐规则，也会产生相同的表面现象。看到幂律或枢纽，不能直接说“优先连接已被证明”。
