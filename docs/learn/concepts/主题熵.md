# 主题熵

**一句话**：主题熵衡量一组文本的主题分布有多分散，不直接测量内容是否连贯。

## 公式
H=−Σ p_k log(p_k)，p_k 为第k主题的比例，0log0约定为0。必须报告对数底。使用自然对数时上限是 ln(K)，底2时上限是 log₂(K)。标准化熵为 H/log(K)，但只有同一标签体系下才可比。

## 例子
某社区90%是技术、10%是艺术，熵低于各占50%。这说明分布更集中，不说明它更能完成技术问答。高熵也可能表示一个开放综合社区有广泛话题。

## 03 的局限
03 用主题熵描述社区混合程度。必须读清它筛选了有足够帖子数的社区。只有一篇帖子的社区天然熵为0，不能据此称其主题高度组织化。

## 本项目怎样用
统一标签和语言，限定最小样本，报告小社区的不确定性。再比较社区间分布与社区名—内容一致性。主题多样性、群体间差异和关系同质性是不同量，不应互相替代。
