# 语言与元数据线索

**一句话**：语言与元数据线索是文本风格和发布形式的可计数特征，用于比较表达差异。

## 02 的四类线索
语义/表达线索包括人称代词和阅读难度；情绪线索包括正负情绪、辱骂与粗话；元数据线索包括@、URL、hashtag；网络线索包括归一化度。它们不是“真实性”的完整定义。

## 分母与工具
按帖词数、每千词比率、每账号平均和全体词频会给不同值。短文本里一个代词就会产生很高比例。Flesch–Kincaid基于特定语言的句长和音节结构，不能未经校准用于中文。词典命中也可能把引用或否定误判成作者情绪。

## 本项目怎样选
只保留与问题相关的线索，如具体问题、引用、链接与针对性确认。先用人工样本检查语言和代码文本。礼貌、第一人称和正面情绪不等于关系建立；情绪少也不等于没有信息功能。

机器人检测器分数属于特定模型与数据分布，不是账号真实自主性或人类身份的概率。
