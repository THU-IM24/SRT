# 语言与元数据线索

**一句话**：语言与元数据线索是可以计数的表达和发布特征，用来比较文本形式，不是“真实性”的完整证明。

## 常见线索

- 语言和人称代词；
- 情绪、辱骂或粗话；
- `@`、URL、hashtag等元数据；
- 度数等网络线索。

这些特征只能说明文本长什么样，不能单独说明账号是谁或是否自主。

## 分母会改变结论

同一个词，按每条评论计数、按每千词计数、按账号平均，结果会不同。短文本中出现一次就可能产生很高比例。Flesch–Kincaid等可读性公式针对特定语言，不能未经校准直接用于中文。

## 只需记住

词典命中可能误判引用、否定和代码；礼貌、第一人称或正面情绪不等于建立关系。检测器分数是模型输出，不是真实身份的概率。
