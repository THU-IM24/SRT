# 帖主回楼

**一句话**：帖主回楼指发帖账号在自己帖子下出现评论，严格版本还要求它回应了别人。

## 三个不同结果
帖主出现率：有评论线程中，出现至少一条帖主评论的比例。帖主回应率：先有非帖主评论后，帖主在规定时间内沿父子关系回复对方的比例。完整往返率：帖主回应后，原评论者又回复的比例。

## 为什么不能只查 author_id 相等
帖主可能在别人到来之前补充资料，也可能连续发自我说明。它们满足“帖主出现”，不满足“回应别人”。同一线程里帖主与他人都出现，也不保证相互回应。

## 分母选择
至少报告：全部帖子、有可观测评论的帖子、有非帖主评论的帖子、父关系可解析且有足够观察时长的帖子。每个指标写自己的分母。不能把每个线程的比例平均和按评论加权的比例混为一谈。

## 本项目用法
先复现宽松“帖主出现”基线，再研究严格回应。去掉主网络自评只适用于主网络，不能先删除原事件再计算回楼。将无评论帖子作为 0 纳入“有评论线程回楼率”会偷换分母。
