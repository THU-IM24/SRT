# 帖主回楼

**一句话**：帖主回楼要区分“帖主出现过”“帖主直接回复了谁”和“双方形成了完整往返”。

## 三个问题不是一个问题

1. 帖主有没有在自己的帖子下发言？
2. 帖主有没有直接回复某条评论？
3. 评论者先发言后，是否得到帖主直接回复，并且帖主的回复又得到评论者回应？

第3种条件最严格，不能用第1种比例代替。

## 一个小例子

A发帖；B评论；A回复B；B又回复A；C评论但没有得到A的直接回复。这里：

- 帖主出现：是；
- B获得帖主直接回复：是；
- B与A完成三步往返：是；
- C是一个未成功的起始机会。

同一条A的回复可能既完成上一段往返，又成为下一段机会的起点，所以不能只按“获回应者”做分母。

## 计算前要固定

机会是评论、评论者，还是帖子？“直接回复”按父消息作者还是帖作者判断？观察窗口是24小时还是7天？临近快照终点的机会是否有完整随访？这些定义不同，比例就不是同一个指标。
