# 数据快照与覆盖

**一句话**：数据快照告诉我们“记录来自什么时候”；覆盖告诉我们“哪些行为有机会被看到”。

## 四种时间不要混用

- **报告期**：论文或数据描述的时间范围；
- **可用日期**：数据什么时候能被研究者拿到；
- **形成日期**：帖子或评论实际发生的时间；
- **观察终点**：我们能可靠看到行为的最后时刻。

例如，2026年10月7日下载的数据，不代表每条评论都只发生在10月7日，也不代表10月7日发布的评论都被完整观察了。

## 当前项目要先问什么

使用公开快照时，先核对文件版本、帖子和评论的时间范围、删除记录、缺失父消息、重复行和字段含义。快照只能说明可见数据，不等于平台完整历史。

## 覆盖缺口会造成什么

- 评论没有被采到，看起来像“没人回复”；
- 父消息缺失，回复树看起来更浅；
- 快照末尾内容没有完整随访，不能用于固定24小时结果。

因此“没有观察到”不总是“没有发生”。

## 只需记住

> 先确认数据在哪个时间、覆盖了谁，再解释网络和行为指标。
