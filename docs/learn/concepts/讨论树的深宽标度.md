# 讨论树的深宽标度

**一句话**：深宽标度比较讨论变大时深度和宽度怎样增长，不能只看共同归一化后的相关。

## 原始量与归一化
评论数为n，最大深度为d，最大单层评论数为w。04将d与w分别除以√n。先确保n是否含根、深度从0还是1、是否只用完整线程。

## 为什么要看原始关系
若d近似常数而w∝n，则d/√n会随n下降，w/√n会随n上升，两者自然呈反向关系。不能只凭这个关系就宣称讨论来自临界分支过程。真正的临界分支基准还要求各量与n的特定增长关系。

## 最低核查
同时给d(n)、w(n)、归一化图、规模筛选和每个规模段的样本数。04图中的至少25评论与完整记录限制，决定它不是所有有评论帖的平坦率。

## 本项目优先级
树深重建可靠后再做。更深不一定更有功能，自回复链、spam或循环错误都能造出大d。把深度与人工承接作为独立量比较。
