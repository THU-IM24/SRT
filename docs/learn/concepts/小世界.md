# 小世界

**一句话**：小世界要求局部比合适的随机基线更聚集，同时整体路径仍接近该基线。

## 两个条件一起看
常用比较是 C/C_rand 明显大于 1，L/L_rand 接近 1。σ=(C/C_rand)/(L/L_rand) 可作摘要，但不能只报 σ 而忽略两个分量、分量大小及随机图生成方式。

## 为什么随机基线重要
相同 N 与 E 的随机图、保留度序列的随机图，回答不同问题。高连接枢纽本身就能缩短路径。若基线没保留它们，可能把度异质性误当成特殊组织。

## 论文启示
01 发现整体并不满足典型小世界的全部条件，但局部自我中心网络可能满足。不能把局部结果写成全图结果。图画得像团簇，也不是小世界检验。

## 本项目最低交付
报告方向、二值化规则、节点全集、最大分量比例、C、L、随机基线的分布和重复次数。先在一个受控月窗验证，再决定是否值得全期计算。小世界即使成立，也只说明结构性质；对话功能必须另测。
