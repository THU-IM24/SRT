# 点赞与讨论规模的标度

**一句话**：标度关系研究讨论扩大时点赞如何增长，增长指数不等于点赞概率或因果效应。

## 公式
若E[U|n]≈a n^β，U是点赞数，n是讨论评论数，β<1称次线性，β=1是线性。n翻倍时期望U约乘2^β。04 v2报告约0.79，这是其数据、筛选和估计方式下的结果。

## 估计细节
分箱均值的log回归、逐帖log(U+1)回归、中位数曲线不是同一估计对象。零点赞、负数异常、极端大帖和分箱边界都要单列说明。不要把回归系数自动叫作幂律分布指数。

## 04 附录做了什么
作者分别检查净分/点踩、作者地位、点赞是否先饱和、争议内容等替代解释。理解这种“提出竞争解释再检验”的设计比照抄一个斜率更重要。我们的快照没有同帖历史点赞轨迹，不能复现需要帖子面板的饱和分析。

## 本项目定位
作为文献基线或稳健性选做。点赞与评论数的相关既可能来自可见度，也可能有共同原因。不能把次线性直接解释成没有认可或没有社会功能。
