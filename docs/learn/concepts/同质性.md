# 同质性

**一句话**：同质性指相似行动者之间的关系比合适的机会基线更多。

## 两种相似
01 区分简介同质性与内容同质性。简介反映声明身份，内容反映实际文本。语言、活跃时间和所在社区也会共同影响可接触机会。相似度高不等于有选择地喜欢相似者。

## 如何检验
对真实边端点计算平均相似度 T_obs。再生成保留必要机会结构的随机边，得到 T_null 分布，报告差值、效应量和不确定性。对照同语言、同月、相近活动量，往往比全平台任意配对更合理。

## 不要混淆
度同配性度量高程度节点是否连接高程度节点；内容同质性度量文本是否相似；社会影响指互动后变得相似。三者不是一个概念。共同模板也能造成文本相似。

## 本项目方案
用前期帖子生成作者内容向量，再比较后期真实连边与机会匹配连边。不能用同一条回复同时决定“相似”和“已互动”。01 的英语与中文结果不同，提醒我们分语言检验；不要预设所有语言结论一致。
