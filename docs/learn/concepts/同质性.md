# 同质性

**一句话**：同质性是指“相似的人彼此连接得比机会随机时更多”。

## 例子

如果同语言账号之间的评论关系明显多于随机配对时的数量，可以说存在语言同质性。相似可以来自简介、语言、主题、活跃时间或活动量。

## 怎样检验

先计算真实连边两端的相似度 $T_{\mathrm{obs}}$，再构造一个保留互动机会的随机基线，得到 $T_{\mathrm{null}}$ 的分布。比较两者的差值或位置，而不是只报真实相似度。

## 三个容易混淆的词

- **同质性**：相似者更容易连边；
- **度同配性**：高连接节点是否连接高连接节点；
- **社会影响**：互动后双方变得相似。

共同模板也会造成文本相似，因此相似不等于主动偏好。
